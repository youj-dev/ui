# Changelog

The packages version together, as one fixed group: `@youj/core`, `@youj/react`, `@youj/motion`, `@youj/sound`, `@youj/icons`, `@youj/illustrations`, `@youj/loaders`, `@youj/miniatures`, `@youj/cli` and `@youj/mcp`. This is the first release; from the next one, entries come from [changesets](https://github.com/changesets/changesets): `pnpm version-packages` writes each package's `CHANGELOG.md`, and this file summarises the release. See [RELEASING.md](RELEASING.md).

## 0.1.0 - 2026-10-20

Youj is in alpha (0.x): APIs can change between minor versions; see the [versioning policy](https://www.youj.dev/docs/versioning).

This is the first release of one design language, carried through components, blocks, motion, visuals and tools, so every part looks and moves like it belongs together. It is an alpha: the foundations are in place, and the APIs will keep settling as people use it.

- **Components and theming:** accessible React components on Base UI and Tailwind, with themes, styles and looks you can make your own, from color and type to shape and motion.
- **Blocks and screens:** ready-made sections, cards, app screens and complete multi-view apps to copy in, all re-themeable.
- **Motion:** transitions, effects and entrances built on tokens, so one speed and one reduced-motion setting reach every piece.
- **Visuals:** animated icons, isometric illustrations, loaders, interactive miniatures and optional interface sounds.
- **Tools:** a CLI that sets Youj up in one command, Create to assemble and export a themed app, and an MCP server so AI tools build with Youj the right way.
- **Accessibility and languages:** keyboard and screen-reader support built toward WCAG 2.2 AA, reduced motion, right-to-left layouts, and translatable copy with language packs.
- **Docs for people and AI:** a page for every part with live previews, search, a Markdown twin of each page, and llms files.
- **Designers:** a Figma kit built from the real tokens and icons.
