# Blocks

Blocks are single screens you install and fill with your data. Building a whole product? See [Examples](?path=/docs/examples-about-examples--docs).

A block is one screen with one job, however complex, built only from public components. Each one in `src/blocks/<group>/` installs as the registry item `<group>-<name>`; examples compose them, never the reverse.
