### Accessibility

Each call to action is a `<section>` named by its own heading (`aria-labelledby`). The heading is an `h2` by default; `headingLevel` changes it.

Form and Contact sales use real `form` elements with labelled fields. Contact sales moves focus to each step's heading as it arrives; its days and times are labelled toggle groups (one tab stop, arrow keys between them) that read each day's open times and say a taken time is taken; a missing time or field is said in an alert and focused; the region is a labelled menu. Proof marks its toggle with `aria-pressed`, announces changes in a live region and hides decorative marks from assistive technology.

Banner checks the reduced-motion setting. The links and buttons are real `a` and `button` elements with the kit’s focus ring.
