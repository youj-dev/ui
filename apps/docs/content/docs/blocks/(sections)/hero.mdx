</BlockStory>

<BlockStory id="terminal" label="Terminal" block="marketing-hero-terminal" story="Default" backdrop="cinnabar">

Introduce a command-line tool with a copyable install command beside an animated terminal session that deploys, then lands what it deployed on the terminal’s corner: the live site, in a window of its own. Pick it when the product is used from a shell.

</BlockStory>

### Accessibility

Each hero is a `<section>` named by its own heading (`aria-labelledby`). The heading is an `h1` by default and an `h2` when you set `embedded`; set `headingLevel` to `1`, `2` or `3` where the page around it needs another.

The product shots, browser frames, terminal sessions and Terminal’s landed site in Split, Product and Terminal are decorative: they are `inert` (Split’s demo screen and Product also `aria-hidden`), so the headline and copy have to carry the meaning; a `media` you pass to Split is read as you give it, so give an image its `alt`. Split’s points are a named list of buttons, with `aria-current` on the one on show; its tour has a Play and Pause button in the window’s title bar and holds while keyboard focus is on the points. Motion’s control panel uses labelled controls (a select and switches) under its own headings.

The animated heroes (Split, Terminal, Product, Motion) check the reduced-motion setting and hold a still frame when it is on: Split shows its whole window, with no tour and no camera. The buttons and links are real `a` and `button` elements with the kit’s focus ring.
