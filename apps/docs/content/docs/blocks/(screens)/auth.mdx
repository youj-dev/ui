### Accessibility

Every screen sits in a `main`; in the split layout the artwork is a separate `aside`, hidden below the `lg` breakpoint. Two-factor uses the kit’s one-time-code input and offers a resend. Device authorization shows its code as one image named letter by letter, or takes it in the same one-time-code input; Authorize and Deny are real buttons that report their progress, and the step you arrive on is announced. In the full flow the leaving step is `inert` and a status region announces the step you arrive on. Links and buttons are real `a` and `button` elements with the kit’s focus ring.
