### Accessibility

Docs has a `main`, a labelled page-tree `nav` that marks the current page with `aria-current`, a sheet for the tree on phones, code tabs that follow the kit’s Tabs keyboard pattern, and a feedback result announced in a status region. Links and buttons are real `a` and `button` elements with the kit’s focus ring.
