### Accessibility

Board has a `header` and one heading. Cards can be moved without a pointer: arrow keys walk the cards, Space picks one up, the arrows carry it and Space drops it, and each step is announced. Calendar’s week is a labelled group whose events open in a popover, with `aria-busy` while it loads and a live region for week changes. Links and buttons are real `a` and `button` elements with the kit’s focus ring.
