### Accessibility

The screens are a `main` with a `header` and labelled sections. The dialogs (change plan, payment method, invite) trap focus and close with Escape; payment errors appear in an alert and a plan change is announced in a live region. The members table has a label, a member’s role is a select labelled with their name, and each member’s actions are a menu labelled the same way. Seat usage is a labelled meter. Usage and charges names its chart and gives the same days as a table for screen readers; focus the chart and the arrow keys walk the days, opening the tooltip, and each SKU row says its usage and whether it is over the allowance in words, with the ring only decorative. Links and buttons are real `a` and `button` elements with the kit’s focus ring.
