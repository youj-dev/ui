### Accessibility

Each screen is a `main` with one heading (`h1` by default; `headingLevel` changes it). Onboarding’s step indicator is labelled, its theme choice is a labelled radio group, and Enter moves to the next step from its text fields. Create workspace announces the result of the address check in a live region. Setup wizard announces step changes in a live region and labels its review sections. Accept invite shows the inviter’s avatar with `alt` text. Links and buttons are real `a` and `button` elements with the kit’s focus ring.
