### Accessibility

Help center has a `main` with one `h1`, a labelled search field and a status region that announces the result count as you type; the contact form announces its outcome in a live region. Search results has a `main`, a labelled `aside` of filters (a sheet on phones), labelled active-filter chips and a status region for the result count. Its query field offers suggestions in a popover, the arrow keys move between result links, and the empty and error states use a list and an alert. Links and buttons are real `a` and `button` elements with the kit’s focus ring.
