### Accessibility

Product detail has one `h1`. The size choices are radio inputs with a label each (a sold-out size says so in its label), the gallery is a labelled carousel whose slides are labelled by position, and the rating is read as text. Order detail is a `main` under a `header` with labelled sections for items, details and shipment, and the shipment progress is a list with a status region. The return flow opens in a dialog that closes with Escape, and row actions sit in a menu with arrow-key navigation. Links and buttons are real `a` and `button` elements with the kit’s focus ring.
