### Accessibility

Changelog is a `main` with one `h1` and a status region for the subscribe result; the subscribe form opens in a popover. Roadmap is a `main` under a `header` with tabs that follow the kit’s Tabs keyboard pattern. Each vote button is labelled with the request it upvotes, the request sheet and the submit dialog trap focus and close with Escape, and a submitted request is announced in a status region. Links and buttons are real `a` and `button` elements with the kit’s focus ring.
