### Accessibility

Each screen has a `header` and one heading (`headingLevel` changes it). The records sit in the [Data grid](/docs/blocks/tables-and-lists#data-grid) block, a `role="grid"` that reports `aria-sort` on sorted columns and `aria-multiselectable` when rows can be selected. Records grid opens a record in a sheet that traps focus and closes with Escape. Records grid shows an order’s progress as an ordered list with the current stage marked by `aria-current`. Links and buttons are real `a` and `button` elements with the kit’s focus ring.
