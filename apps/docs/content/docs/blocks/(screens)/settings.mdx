### Accessibility

Settings and Profile use the kit’s Tabs, so the tab list is named, Left and Right Arrow move between tabs and the panel follows the selected one. Settings has one page heading (`headingLevel` changes it) and labelled fields and switches. The invite and confirm steps open in dialogs. Profile has a labelled `aside` and `nav`, the avatar is decorative (`alt=""`) because the name sits beside it, and the activity heatmap is one image with a text label. Links and buttons are real `a` and `button` elements with the kit’s focus ring.
