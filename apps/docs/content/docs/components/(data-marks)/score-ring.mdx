## Installation & usage

<InstallTabs name="score-ring" noImport />

Use a score ring when one score carries a verdict: a security or health score with its letter grade, a compliance rating, a quality bar. The whole ring is the range and the lit ticks are the score, clockwise from the top, so how far round it reaches reads before the number; the tick at the score reaches past the rest. Pair it with the number itself (a [Stat Card](/docs/components/stat-card)'s `StatValue`) when the exact score matters. For a value on a scale with named bands and both ends shown, use a [Gauge](/docs/components/gauge). The [Score overview](/docs/blocks/status-and-health#score-overview) card is built on it.

```tsx
import { ScoreRing, type ScoreGrade } from '@youj/react'

const grades: ScoreGrade[] = [
  { from: 0, label: 'F', tone: 'danger' },
  { from: 60, label: 'C', tone: 'warning' },
  { from: 75, label: 'B', tone: 'success' },
  { from: 90, label: 'A', tone: 'success' },
]

<ScoreRing value={77} grades={grades} label="Security score" />
```

Each grade starts a band at `from` that runs up to the next one, in any order; the ring takes the band's `tone` and shows its `label`. Without grades it shows the score in `tone` (the accent by default). `min` and `max` set the range (0 to 100 by default) and the score is held inside it. `ticks` sets how many make the ring (40 by default), `size` is `sm` (64px), `default` (96px) or `lg` (128px), and `children` replaces what sits in the middle.

<ReferenceRow title="Accessibility" summary="Meter, value text, busy">

### Accessibility

- A `meter` (your `label`, or the labels' "Score") with `aria-valuemin`, `aria-valuemax` and `aria-valuenow`, and a value text of the score of the maximum, then its grade: "77 of 100, grade B".
- `busy` sets `aria-busy`, so assistive tech knows the reading may change.
- The ticks and the sweep are decorative; the value text says the score. A grade is a letter as well as a tone, never color alone.
- A dial turns clockwise in every script, so the ring keeps its direction under RTL.
- Its built-in text comes from the labels, so `<YoujProvider labels>` translates it.

</ReferenceRow>
