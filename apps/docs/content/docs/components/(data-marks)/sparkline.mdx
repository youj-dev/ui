## Installation & usage

<InstallTabs name="sparkline" noImport />

Use a sparkline to show the shape of recent values next to the number they lead to: requests per minute beside the current rate, a week of revenue in a KPI, a trend in each row of a list. It has no axes, no tooltip and no legend, so it says "rising" or "falling" and nothing more. When people need to read values off it, use a [Chart](/docs/components/chart). Inside a KPI card, pass it to [Stat Card](/docs/components/stat-card)'s `chart` slot.

```tsx
import { Sparkline } from '@youj/react'

<Sparkline data={[12, 14, 13, 17, 16, 19, 22]} className="h-8 w-32" label="Signups this week, rising" />
```

It stretches to its box, so give it a height (the default is `h-8`) and a width from its container. The stroke keeps its width at any size, and the curve is monotone: it passes through every point and never overshoots one, so a flat stretch stays flat.

</Example>

<ReferenceRow title="Accessibility" summary="ARIA">

### Accessibility

- With `label` it's an image (`role="img"`) named by the label. Write the label as the takeaway: "Revenue, last 30 days, rising".
- Without `label` it's `aria-hidden`. Say what it shows in the text beside it.
- A trend reads left to right in every text direction, so the sparkline sets `dir="ltr"` on itself.

</ReferenceRow>
