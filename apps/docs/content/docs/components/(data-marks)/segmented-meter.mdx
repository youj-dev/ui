## Installation & usage

<InstallTabs name="segmented-meter" noImport />

Use a segmented meter for usage people compare across a panel: threads, disk, a backlog, seats. The discrete cells make levels countable, and the cells past a threshold light in its tone, so the warning shows exactly where usage crossed the line. For one headline score, use a [Gauge](/docs/components/gauge); for progress through a task, use [Progress](/docs/components/progress).

```tsx
import { SegmentedMeter } from '@youj/react'

<SegmentedMeter label="Disk" value={84} thresholds={[{ value: 80, tone: 'warning', label: 'High' }]} />
<SegmentedMeter label="Backlog" value={870} max={2400} format={{}} />
```

The value on the end side is a percentage of the range by default; pass `format` (`Intl.NumberFormat` options) to show the raw value, as the backlog does. `segments` sets the number of cells (default 40), `tone` the lit cells' tone below every threshold (default `neutral`, the ink) and `showValue={false}` hides the value.

</Example>

<ReferenceRow title="Accessibility" summary="ARIA">

### Accessibility

- It's a `meter` (Base UI Meter) named by its visible `label`; without one, give it `aria-label`.
- The value is spoken with its band: "88%, High". A warning or danger band without a label is spoken as "Warning" or "Critical".
- The cells are hidden from assistive tech. They fill from the inline start, so right to left in RTL.

</ReferenceRow>
