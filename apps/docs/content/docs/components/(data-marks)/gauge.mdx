A health index gauge with zones and a status, and buttons for 38, 74 and 91 that move it.

`gradient` lays the bands under the fill as zones: each band faint in its own tone, split from the next by a hairline gap, so the whole scale reads at once, like the zones on a dial, while the fill keeps the one tone of the band the value is in. Without thresholds the zones are danger, warning and success thirds. Use it for scores where high is good; the band still names the value.

<Story id="thresholds" label="Thresholds">

<ComponentPreview name="gauge/thresholds" height={220} />

Three load gauges at 34, 76 and 95 percent, in different sizes.

Each threshold starts a band that runs up to the next one. The fill takes the band's `tone`, and the band's `label` becomes the sub-label under the value (pass children to write your own). A value crossing into the next band crossfades the fill to the new tone.

## Installation & usage

<InstallTabs name="gauge" noImport />

Use a gauge for a single score between known ends that people read at a glance: a health index, a load, a quota. The value sits in the bowl and the word for its band sits under it, between the range's two ends, so "74, Strained" reads before anyone looks at the arc. The arc is a thin band on a scale of ticks, and a fine needle across the band marks the value. For several resources side by side, use [Segmented Meter](/docs/components/segmented-meter); for a trend, use a [Sparkline](/docs/components/sparkline).

```tsx
import { Gauge } from '@youj/react'

<Gauge
  value={74}
  label="Health index"
  gradient
  thresholds={[
    { value: 0, tone: 'danger', label: 'Critical' },
    { value: 50, tone: 'warning', label: 'Strained' },
    { value: 80, tone: 'success', label: 'Nominal' },
  ]}
/>
```

`min` and `max` default to 0 and 100. `format` takes `Intl.NumberFormat` options, so units and percentages follow the locale. `size` is `sm`, `default` or `lg`; `sm` leaves the range's ends out.

<ReferenceRow title="Accessibility" summary="ARIA">

### Accessibility

- It's a `meter` (Base UI Meter) with `aria-valuenow`, `aria-valuemin` and `aria-valuemax`. Name it with `label`, or point `aria-labelledby` at a visible heading.
- The value is spoken with its band: "74, Strained". A warning or danger band without a label is spoken as "Warning" or "Critical" (translated through `labels`), so color is never the only signal.
- The arc and the animated number are hidden from assistive tech; the meter's value text carries both.
- A dial turns clockwise in every script, so the arc keeps its direction in right-to-left layouts.

</ReferenceRow>
