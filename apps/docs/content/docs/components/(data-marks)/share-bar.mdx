## Installation & usage

<InstallTabs name="share-bar" noImport />

Use a share bar to show how much of a whole one row takes: a plan's share of revenue, a suite's pass rate, a volume against its size. It's a mark, not a chart: no axis and no tooltip, so put the number beside it. For the shape of values over time use a [Sparkline](/docs/components/sparkline); for how a whole divides into parts at once, a [Treemap](/docs/components/treemap).

```tsx
import { ShareBar } from '@youj/react'

<ShareBar value={0.412} segments={24} tone="accent" />
<ShareBar value={268} max={480} tone="neutral" label="Build minutes used" />
```

`value` is a share from 0 to 1, or a value out of `max`. Without `segments` it's one solid bar; with it, it's a run of that many cells, and the value rounds to whole cells: any share above zero lights at least one, and only a full share lights them all. `tone` takes the accent, a chart color (`chart-1` to `chart-5`), a status (`success`, `warning`, `danger`) or `neutral`. Give it a width from its container; the height is 6px solid and 12px in cells, and a class changes it.

With `parts` the fill is a whole split into its parts, each in its `tone` (the chart colors in order by default), from the inline start; `max` defaults to their sum, so they fill the bar. In cells, each part gets whole cells and any part above zero keeps one. `mark="tick"` draws the segments as hairlines on a taller bar instead of cells. `active` lights one part and quiets the rest: pair the bar with a [Breakdown List](/docs/components/breakdown-list) and pass its `onActiveChange` here, so pointing at a row lights its segment.

```tsx
<ShareBar parts={[{ value: 61_420 }, { value: 38_960 }, { value: 21_310 }]} active={active} />
```

In a table where every row is a share of the same whole, pass the largest share as `max` so the top row fills its bar and the rest compare to it.

### Accessibility

- With `label`, `role="meter"` with `aria-valuenow`, `aria-valuemin`, `aria-valuemax` and a percentage as `aria-valuetext`.
- Without `label` (or `aria-label`, `aria-labelledby`) it's `aria-hidden`: say the value in the text beside it.
- With `parts` and a `label`, the meter speaks each part's share when every part has a `label`: "Online 75%, Away 25%".
- The fill grows from the inline start, so it runs right to left in RTL.

</ReferenceRow>
