## Installation & usage

<InstallTabs name="cell-bar" noImport />

Use a cell bar where a total's length and its rhythm both matter: spend by month against a budget, hours by week against a plan, a quarter's revenue by month. Rows of them on one `max` compare totals, and each bar still shows how its total grew. For shares of a whole use a [Share Bar](/docs/components/share-bar); for one settled or pending amount, a [Hatched Bar](/docs/components/hatched-bar). The [Plan vs actual](/docs/blocks/rankings-and-breakdowns#plan-vs-actual) card is built on it.

```tsx
import { CellBar } from '@youj/react'

<CellBar
  label="nightly-summarizer, by month"
  cells={[
    { label: 'Aug', value: 980 },
    { label: 'Sep', value: 1060 },
    { label: 'Oct', value: 1120, projected: true },
  ]}
  max={10000}
  target={6240}
  tone="warning"
  formatValue={(v) => `$${v.toLocaleString('en-US')}`}
/>
```

Each cell is as wide as its `value`, with a 2px gap between cells; the bar runs to its total on a scale that ends at `max` (by default the total, or the target if larger). `projected` cells are hatched in the tone. `target` puts a dashed tick on the same scale, and `targetLabel` names it over the tick. `formatValue` writes amounts in the tooltips, captions and summary.

<ReferenceRow title="Accessibility" summary="Keyboard, focus, screen readers">

### Accessibility

- A named `group` (your `label`, or the labels' "Cell bar") described by its total, the part that is projected and the target ("$9,710 in all. $3,540 of it projected. Target $6,240.").
- The cells are a list; each is read with its period and amount, and says when it is projected ("Oct: $1,120, projected").
- One tab stop. The arrow keys walk the cells (mirrored in RTL), `Home` and `End` go to the ends, and focus shows the same tooltip as hovering.
- Projected cells are hatched as well as tinted, and the target is a dashed tick, so neither leans on color alone.
- Its built-in text comes from the labels, so `<YoujProvider labels>` translates it.

</ReferenceRow>
