## Installation & usage

<InstallTabs name="aspect-ratio" noImport />

Use an aspect ratio around images, video, embeds and their placeholders in fluid layouts. The box reserves its height from its width before the media arrives, so nothing below it jumps when it does.

```tsx
import { AspectRatio } from '@youj/react'

export function Thumbnail() {
  return (
    <AspectRatio ratio={16 / 9} className="overflow-hidden rounded-lg">
      <img src="/keynote.jpg" alt="The keynote stage" className="size-full object-cover" />
    </AspectRatio>
  )
}
```

`ratio` is width over height as a number: `16 / 9`, `1`, `4 / 5`. It's the CSS `aspect-ratio` property, so it needs no JavaScript and renders the same on the server. Give the child `size-full` (and `object-cover` for media) to fill the box. The API matches shadcn/ui's Aspect Ratio.

</Example>
