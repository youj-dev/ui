## Installation & usage

<InstallTabs name="breakdown-list" noImport />

Use a breakdown list as the key to a split bar: revenue by category, cash by account, seats by status. Each row is a color marker, a name, a value and its share of the total. For a few parts inside a stat tile use [StatBreakdown](/docs/components/stat-card); for one row's share of a whole, a [Share Bar](/docs/components/share-bar) on its own.

```tsx
import { useState } from 'react'
import { BreakdownList, ShareBar } from '@youj/react'

const [active, setActive] = useState<number | null>(null)

<ShareBar parts={channels.map((c) => ({ value: c.value }))} active={active} />
<BreakdownList items={channels} format={{ style: 'currency', currency: 'EUR' }} active={active} onActiveChange={setActive} />
```

Both take the chart colors in order, so give them the same items and the rows match the segments without naming a tone; a `tone` on an item (the accent, a status, a chart color or `neutral`) colors both when you pass it to both. Shares are out of the items' sum, or your `total`. `variant="tiles"` leads each row with its value in a small panel, for counts; `showShare={false}` drops the percentages.

</Example>

<ReferenceRow title="Accessibility" summary="List, keyboard">

### Accessibility

- It is a list; each row reads its name, detail, value and share in order. Name the list with `aria-label` when nothing visible names it.
- The rows are one tab stop. The arrow keys, Home and End move between them, and focus makes a row the active one, so a keyboard lights the bar's segments as a pointer does. Focus leaving the list clears it.
- The markers are decorative (`aria-hidden`); the name says which part is which.

</ReferenceRow>
