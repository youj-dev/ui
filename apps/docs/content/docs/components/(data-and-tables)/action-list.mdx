## Installation & usage

<InstallTabs name="action-list" noImport />

Use an action list where a screen asks someone to do things: alerts that need a decision, setup steps, renewals coming due, reviews waiting. Each row is an icon tile, a title, one line of detail, an optional chip and the row's own action. For a stream of events that only informs, use a [Notification Center](/docs/components/notification-center); for one record's fields, a [Property List](/docs/components/property-list).

```tsx
import { CalendarIcon, ShieldAlertIcon } from '@youj/icons'
import { ActionList, ActionListItem, Button } from '@youj/react'

<ActionList title="Waiting on you" count={9} action={<Button variant="ghost" size="sm">View all</Button>}>
  {alerts.map((alert) => (
    <ActionListItem
      key={alert.id}
      icon={<ShieldAlertIcon />}
      tone="danger"
      title={alert.title}
      detail={alert.detail}
      meta={<><CalendarIcon /> {alert.due}</>}
      action={<Button variant="secondary" size="sm" onClick={() => resolve(alert.id)}>Resolve</Button>}
    />
  ))}
</ActionList>
```

`tone` colors the icon tile (`neutral`, `accent`, `info`, `success`, `warning` or `danger`); the chip takes the same tone unless you pass `metaTone`. `count` sits in a chip beside the title and can be larger than the rows you show, with the header `action` linking to the rest. Key every row by a stable id: the rows are a [PresenceList](/docs/motion/presence-list), so removing one when it is done fades it out and closes the gap.

Below 20rem of its own width, the chip and the action wrap under the text instead of squeezing it.

<ReferenceRow title="Accessibility" summary="Region, list">

### Accessibility

- With a `title` it is a `section` named by its heading (`headingLevel`, 3 by default), so it is a landmark region; the rows are a list.
- The icon tile is decorative (`aria-hidden`); the title and detail carry the meaning, and the chip is plain text.
- Name each row's action for what it does ("Rotate key", not "Go"), since a screen reader may reach it out of its row.
- A row on its way out is inert, so focus can't land on it.

</ReferenceRow>
