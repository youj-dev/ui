## Installation & usage

<InstallTabs name="table" noImport />

Use the Table parts for a small, static table: a few rows with no sorting or filtering of their own. Their dividers sit on the cells, not the rows, so rows can move with [Presence List](/docs/motion/presence-list) and take their borders with them.

```tsx
import { Table, TableBody, TableCell, TableHead, TableHeader, TableRow } from '@youj/react'

<Table aria-label="Domains">
  <TableHeader>
    <TableRow>
      <TableHead>Domain</TableHead>
      <TableHead className="text-end">Redirects</TableHead>
    </TableRow>
  </TableHeader>
  <TableBody>
    <TableRow>
      <TableCell>acme.dev</TableCell>
      <TableCell className="text-end tabular-nums">2</TableCell>
    </TableRow>
  </TableBody>
</Table>
```

### Accessibility

- Name a table with `aria-label` or a `<TableCaption>`; headers are `<th>` cells, so each cell is read with its column.
- A table that scrolls sideways takes a Tab stop of its own and is named, so the keyboard can scroll it.
- Rows that move with Presence List keep their borders, since the dividers sit on the cells.
