## Installation & usage

<InstallTabs name="json-viewer" noImport />

Use a JSON viewer for data people read and copy from rather than edit: an event in a logs inspector, a webhook delivery, an API response, a stored document or a config. For code to read with syntax highlighting, use a [Code Block](/docs/components/code-block). For a hierarchy people act on, such as files and folders, use a [Tree View](/docs/components/tree-view). For a short set of named fields, use a [Property List](/docs/components/property-list).

```tsx
'use client'

import { JsonViewer } from '@youj/react'

export function DeliveryPayload({ delivery }: { delivery: WebhookDelivery }) {
  return (
    <JsonViewer
      label="Payload"
      value={delivery.payload}
      className="max-h-[480px]"
      onCopyText={(text, { part }) => track('payload_copied', { part })}
    />
  )
}
```

`value` takes anything `JSON.parse` returns, or a plain object or array. Values are shown as `JSON.stringify` reads them: a Date as its ISO string, a bigint as its digits. A value that holds itself shows "Circular reference" there instead of opening forever.

`defaultExpandDepth` sets how deep objects and arrays start open: 1, the default, opens the ones at the top; 0 opens none; `Infinity` opens all. Rows opened or closed by hand stay that way when `value` changes, matched by their path. `label` names the viewer in its header and to screen readers. `onCopyText(text, { part, path })` hears every copy that succeeded, with `part` `"value"` or `"path"` and the row's path (`[]` for the header's).

Give the viewer a height (`max-h-*` or `h-*`) and the tree scrolls under its header. Rows wrap long values rather than scrolling sideways. The tree reads left to right on any page, as code does.

### Props

<PropsTable name="JsonViewer" />

#### Data attributes

The root is `json-viewer` in `data-slot`, with `data-reduced-motion`. Its header is `json-viewer-header`, holding `json-viewer-label` and the buttons `json-viewer-expand` and `json-viewer-copy-all`. The tree is `json-viewer-tree`, and each row's item `json-viewer-item`, with what it shows in `data-yj-kind` (`object`, `array`, `string`, `number`, `boolean`, `null`, `undefined`, `range` or `text`) and, on a value, its path as JavaScript reads it in `data-yj-path`. Inside an item, `json-viewer-row` holds `json-viewer-text` with `json-viewer-key`, `json-viewer-value` and `json-viewer-count`, and the row's buttons `json-viewer-actions` with `json-viewer-copy` and `json-viewer-copy-path`.

</ReferenceRow>

#### Reduced motion

Rows appear and disappear at once, with no height animation, and the chevrons and the copy icons show their new state without turning or drawing. Everything else, including the announcements, is the same.

<ReferenceRow title="Accessibility" summary="Keyboard, names, copying">

### Accessibility

- It's a `tree` named by `label` ("JSON" by default), with `aria-expanded` on every row that opens. A row is named by what it shows, with counts in words: `customer: 4 keys`, `tags: 2 items`, `code: "card_declined"`. A range reads `Items 0 to 99`, and an opened long string `message: 123 characters`, with its whole text in the row under it.
- One Tab stop: the focused row carries `tabIndex={0}` and the rest `-1`. Its Copy value and Copy path buttons come next in the Tab order, so the keyboard reaches them without a pointer; other rows' buttons aren't in the page until hovered or focused.
- A copy is announced politely as "Copied". A clipboard that refuses (no permission, an insecure page) is announced at once as "Couldn’t copy", and the button's tooltip says the same.
- The tree reads left to right on a right-to-left page too, as code does, so <kbd>→</kbd> always opens. The header follows the page.
- With sound on, the buttons play `tap` and a copy `success`, or `error` when the clipboard refuses. `sound={false}` keeps it silent.

| Key | Does |
| --- | --- |
| <kbd>↑</kbd> <kbd>↓</kbd> | Move between visible rows. |
| <kbd>→</kbd> | Opens a closed row, or moves into an open one. |
| <kbd>←</kbd> | Closes an open row, or moves out to the row it's in. |
| <kbd>Home</kbd> / <kbd>End</kbd> | The first or last visible row. |
| <kbd>*</kbd> | Opens every row beside this one that opens. |
| Typing | Jumps to the next row whose key starts with the letters typed. |
| <kbd>Enter</kbd> | Opens or closes the row. |
| <kbd>Ctrl</kbd>+<kbd>C</kbd> / <kbd>⌘</kbd>+<kbd>C</kbd> | Copies the row's value, unless you've selected text, which the browser copies. |
| <kbd>Tab</kbd> | From a row, its Copy value and Copy path buttons, then out of the tree. |
