## Installation & usage

<InstallTabs name="property-list" noImport />

Use a property list for the fields of one record in a detail panel or a drawer: a deal's owner, stage and value, a ticket's assignee and priority, a file's size and dates. Each row is an icon, a label and a value, and the value is any node. Helpers lay out the common kinds and format them in the app's locale. For many records side by side, use a [data table](/docs/blocks/tables-and-lists). For a form people fill in from scratch, use [Field](/docs/components/field).

```tsx
import { BanknoteIcon, CircleDashedIcon, CircleUserIcon } from '@youj/icons'
import { PropertyList, PropertyListItem, PropertyMoney, PropertyPerson, PropertyStatus } from '@youj/react'

export function DealProperties({ deal }: { deal: Deal }) {
  return (
    <PropertyList>
      <PropertyListItem icon={<CircleUserIcon />} label="Owner">
        <PropertyPerson name={deal.owner.name} src={deal.owner.avatar} />
      </PropertyListItem>
      <PropertyListItem icon={<CircleDashedIcon />} label="Stage">
        <PropertyStatus tone="warning">Proposal</PropertyStatus>
      </PropertyListItem>
      <PropertyListItem icon={<BanknoteIcon />} label="Value">
        <PropertyMoney value={deal.value} currency="USD" />
      </PropertyListItem>
    </PropertyList>
  )
}
```

The label column is 9rem wide and every value starts after it. Set `--property-label-width` on the list (`className="[--property-label-width:--spacing(28)]"`) for shorter or longer labels. A long value truncates on one line; `PropertyText` shows the full text on hover. When the list is narrower than 20rem, each label sits above its value.

| Helper | Shows |
|---|---|
| `PropertyPerson` | an avatar (a photo, or the initials) and the name |
| `PropertyTag` | a quiet Badge; any Badge `variant` passes through |
| `PropertyStatus` | a colored dot and its label; `tone` is `neutral`, `accent`, `success`, `warning`, `danger` or a chart tone |
| `PropertyProgress` | a bar and its percent, named by the row's label |
| `PropertyDate` | a date in a `<time>`; `format` takes `Intl.DateTimeFormat` options |
| `PropertyMoney` | an amount in its `currency`, whole amounts without cents |
| `PropertyAge` | how long since `since`: "12 days", "3 months", "2 years" |
| `PropertyText` | text that truncates |

<ReferenceRow title="Accessibility" summary="Description list, edit buttons">

### Accessibility

- It is a description list: each row is a `dt` and its `dd`, so a screen reader reads every label with its value.
- Icons and the status dot are decorative (`aria-hidden`). The label and the status text carry the meaning.
- `PropertyProgress` is a `progressbar` named by its row's label, with its value as text.
- Edit buttons are named "Edit" and the row's label (`editProperty` in `YoujProvider`'s labels), and stay in the tab order while hidden, showing as soon as they take focus.
