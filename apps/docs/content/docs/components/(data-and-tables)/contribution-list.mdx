## Installation & usage

<InstallTabs name="contribution-list" noImport />

Use a contribution list to explain a figure: a forecast against a typical week, this month's bill against last month's, a score against its target. It is a waterfall chart told as a list: the baseline, each step with its sign, and the total, highlighted. For one value against another use a [Diff Bar](/docs/components/diff-bar); for how a total splits into parts, a [Breakdown List](/docs/components/breakdown-list).

```tsx
import { MegaphoneIcon, TagIcon } from '@youj/icons'
import { ContributionList, runningTotals } from '@youj/react'

<ContributionList
  baseline={{ label: 'A normal week', value: 1840 }}
  items={[
    { icon: <MegaphoneIcon />, label: 'Launch post', detail: 'Goes out Tuesday', value: 310 },
    { icon: <TagIcon />, label: 'Price change', detail: 'Starter goes to €12', value: -120 },
  ]}
  total={{ label: 'Expected next week' }}
/>

runningTotals(1840, [{ value: 310 }, { value: -120 }]) // [1840, 2150, 2030]
```

The total's value is never passed: it is the baseline plus every step, so the list always adds up. `runningTotals` gives the same numbers for a headline elsewhere on the page. `format` and `locale` set how every figure reads; the steps always carry their sign.

Beside each value a thin mark shares one scale, from the lowest running total to the highest: the baseline and the total are ticks at their place, and each step is a bar from where the figure was to where it went. Rises take the good ink and falls the bad one; `invert` swaps them where a fall is good news, as with costs. `marks={false}` drops them, and they hide on their own below 28rem.

<ReferenceRow title="Accessibility" summary="Ordered list">

### Accessibility

- It is an ordered list read top to bottom: the baseline, each step with its signed value, then the total. Name it with `aria-label` when no heading does.
- The icons and the marks are decorative (`aria-hidden`); the label, detail and signed value carry the meaning.
- The bars grow from the inline start's side of the scale, so the marks mirror in RTL.
