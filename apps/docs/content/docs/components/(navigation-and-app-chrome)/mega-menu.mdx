## Installation & usage

<InstallTabs name="mega-menu" noImport />

Use a mega menu when a top-level section has more destinations than a plain dropdown holds well: a product with a dozen features, a resources hub, a developer portal. Each panel groups links into captioned columns, and a featured card at the end can carry a launch or a case study. For a handful of links, a [Navigation Menu](/docs/components/navigation-menu) with plain panels is enough. Actions (sign out, delete, switch theme) belong in a [Dropdown Menu](/docs/components/dropdown-menu), not in navigation.

The mega menu parts go inside a [Navigation Menu](/docs/components/navigation-menu): `MegaMenuContent` takes the place of `NavigationMenuContent`.

```tsx
import {
  MegaMenuContent,
  MegaMenuFeatured,
  MegaMenuGroup,
  MegaMenuLink,
  NavigationMenu,
  NavigationMenuItem,
  NavigationMenuList,
  NavigationMenuTrigger,
} from '@youj/react'
import { RocketIcon, TerminalIcon } from '@youj/icons'

export function ProductMenu() {
  return (
    <NavigationMenu aria-label="Main">
      <NavigationMenuList>
        <NavigationMenuItem value="product">
          <NavigationMenuTrigger>Product</NavigationMenuTrigger>
          <MegaMenuContent featured={<MegaMenuFeatured href="/blog/2-0" eyebrow="New" title="Northwind 2.0" />}>
            <MegaMenuGroup title="Build">
              <MegaMenuLink href="/deployments" icon={<RocketIcon size={16} />} title="Deployments" description="Git-push to preview, promote to prod." />
              <MegaMenuLink href="/functions" icon={<TerminalIcon size={16} />} title="Functions" description="Server code that scales to zero." />
            </MegaMenuGroup>
          </MegaMenuContent>
        </NavigationMenuItem>
      </NavigationMenuList>
    </NavigationMenu>
  )
}
```

Each `MegaMenuGroup` is a column, 15.5rem wide, under its caption. `MegaMenuLink` is a destination: an icon tile, a title and one line of description. It closes the menu when it's followed. A [Youj icon](/docs/icons) in the tile plays while the link is hovered or focused, with no wiring.

### In a header

A mega menu usually lives in an [App Header](/docs/components/app-header), inside `AppHeaderNav`, which hides it below `md`. Phones get the same destinations as a flat list in `AppHeaderMenu`.

<ReferenceRow title="Accessibility" summary="Keyboard, ARIA, focus">

### Accessibility

- Each column is a `group` labeled by its caption.
- A link is named by its title, and its description is read after it (`aria-describedby`). The featured card is named by its eyebrow and title. Icons and art are hidden from assistive technology.
- Triggers are buttons with `aria-expanded`. The whole menu is a `nav` landmark, named by the `NavigationMenu`'s `aria-label`.

| Key | Action |
| --- | --- |
| Enter / Space / ↓ | Open the focused trigger's panel. |
| Tab | Move through the panel's links, then on to the next trigger. |
| Escape | Close the panel and return focus to its trigger. |

</ReferenceRow>
