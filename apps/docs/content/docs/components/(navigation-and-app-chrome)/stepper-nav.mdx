## Installation & usage

<InstallTabs name="stepper-nav" noImport />

Use it at the top (or down the side) of a flow where each step is its own page: checkout, onboarding, workspace setup. It shows where the reader is and lets them go back to any step they've done. It doesn't run the flow: validation, saving and what "Continue" does stay with your app, and upcoming steps can't be jumped to. When the steps live on one page and the component should own them, use a [Wizard](/docs/components/wizard). To show progress without links, use a [Stepper](/docs/components/stepper) on its own.

```tsx
import { StepperNav } from '@youj/react'

const steps = [
  { id: 'account', title: 'Account', description: 'Email and password' },
  { id: 'workspace', title: 'Workspace', description: 'Name and URL' },
  { id: 'plan', title: 'Plan' },
  { id: 'invite', title: 'Invite', optional: true },
]

export function SetupProgress({ step }: { step: number }) {
  return <StepperNav aria-label="Setup" steps={steps} current={step} href={(i) => `/setup/${steps[i]!.id}`} />
}
```

`current` is the index of the step the reader is on, usually read from the route. `href` maps a step to its page. The done steps and the current one become links, and the ones ahead stay plain text. Set `current` to `steps.length` once the flow is done, and every step shows its check.

Each step is a [Stepper](/docs/components/stepper) step: a `title`, an optional `description`, `optional` to add "Optional" under the title, and `error` to mark a step that needs another look. `onNavigate` fires as a step link is followed, which is where a client-side router takes over.

#### Reduced motion

The connectors fill and drain at once, and a finished step's check appears already drawn. Colors change instantly. The links, statuses and names are unchanged.

<ReferenceRow title="Accessibility" summary="ARIA, focus">

### Accessibility

- It's a `nav` landmark named "Progress" by default. Name it after the flow with `aria-label` ("Setup", "Checkout").
- The steps are an ordered list. The current step carries `aria-current="step"`, and every step's name ends with its status ("Workspace, current step", "Account, completed", "Plan, not started"), so the progress reads the same without the colors.
- Done steps and the current one are links. Upcoming steps aren't focusable, since they can't be reached yet.
- Titles hidden below `sm` are still in the accessible name.

</ReferenceRow>
