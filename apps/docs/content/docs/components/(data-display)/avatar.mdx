<Story id="colors" label="Colors">

<ComponentPreview name="avatar/colors" height={180} />

Initials tinted with a colour picked from each person's email.

`colorSeed` on `AvatarFallback` tints the initials with one of the theme's five chart colours, chosen from the seed: pass something stable (a user id or an email) and a person keeps their colour in every list and on every visit. The tint is drawn like the theme's inks, a thin wash with the initials mixed toward the text colour, so it follows the preset and holds contrast in light and dark. `avatarColor(seed)` returns the same colour's name (`chart-1`…`chart-5`) for anything else you want to match, such as a `Badge color`.

```tsx
<AvatarFallback colorSeed={user.email}>{initials}</AvatarFallback>
```

## Installation & usage

<InstallTabs name="avatar" noImport />

Use Avatar for an author, assignee or member. Show the person’s name alongside it when space allows. For a company or project, consider an icon or logo instead of initials.

```tsx
import { Avatar, AvatarFallback, AvatarImage } from '@youj/react'

export function Author() {
  return (
    <Avatar>
      <AvatarImage src="/people/ana.jpg" alt="Ana Lima" />
      <AvatarFallback>AL</AvatarFallback>
    </Avatar>
  )
}
```

The fallback shows until the image has actually loaded, and stays if the image fails, so there's never a broken-image frame. When the image arrives, it fades in over the muted disc.

</Example>

### Props

#### Avatar

<PropsTable name="Avatar" />

#### AvatarImage

<PropsTable name="AvatarImage" />

`AvatarImage` takes an image's `src` and `alt`, and Base UI's `onLoadingStatusChange`. `AvatarFallback` takes Base UI's `delay`, in milliseconds, to hold the initials back briefly on fast connections, and `colorSeed` to tint them with a chart colour picked from the seed. `AvatarBadge`, `AvatarGroup` and `AvatarGroupCount` render plain elements and take their usual attributes.

</ReferenceRow>

### Motion

#### Reduced motion

A loaded image replaces the initials at once instead of fading in. Nothing else about the avatar moves.

</ReferenceRow>

<ReferenceRow title="Accessibility" summary="ARIA, announcements">

### Accessibility

- An avatar next to a visible name is decorative. Mark it `aria-hidden` and give its image an empty `alt`, as in the demo, so the name isn't read twice.
- An avatar on its own, such as one in a stack, needs the person's name. Put it in the image's `alt`, and give the fallback `role="img"` and an `aria-label` with the same name, so it reads the same before the image loads or if it fails.
- The status dot is color only. Say the status in text nearby, or include it in the name, as in "Priya Raman, online".
- Give the group count words for screen readers, such as "and 4 more", rather than "+4".

</ReferenceRow>
