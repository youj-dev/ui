## Installation & usage

<InstallTabs name="diff-viewer" noImport />

Use a diff viewer wherever someone reviews a change to code or config: a pull request, a deploy's changes, a config history, an AI edit waiting for approval. For a snippet that isn't a change, use [Code Block](/docs/components/code-block).

```tsx
import { DiffViewer } from '@youj/react'

export function ConfigChange({ previous, current }: { previous: string; current: string }) {
  return <DiffViewer before={previous} after={current} filename="config/app.json" language="json" />
}
```

- **Two versions or a patch.** `before` and `after` are compared line by line. Line endings don't count (CRLF reads as LF), but a missing newline at the end of the file does, as in git. Or pass `patch`, a unified diff; only its first file is shown, and the lines between its hunks can't be opened because the patch doesn't carry them.
- **Highlighting** is CodeBlock's built-in tokenizer, so `language` takes the same values (`ts`, `tsx`, `json`, `yaml`, `css`, `py`, `go`…). It produces tokens, never HTML.
- **Unchanged lines** fold beyond `context` lines on each side of a change (3 by default) into a row that opens in place. `context={Infinity}` shows every line.
- **View and wrap** are `view`/`defaultView`/`onViewChange` and `wrap`/`defaultWrap`/`onWrapChange`, so an app can remember them.
- **Copy** copies `after`, or the patch when you passed one.

<ReferenceRow title="Accessibility" summary="Table, keyboard, announcements">

### Accessibility

- The viewer is a `figure` named by the file name, and the diff is a table whose caption names the file and counts the additions and deletions.
- Each changed line reads its change and number first: "Added line 12: …", "Removed line 9: …". Line numbers and the +/− signs are decorative and can't be selected, so copying by hand takes only the code. In the split view, the columns are headed Before and After.
- The diff is a focusable region. J and K, or Alt+↓ and Alt+↑, step to the next and previous change (described on the region, and as `aria-keyshortcuts`); the header's position, "Change 3 of 7", is announced politely. Previous and Next change are buttons too.
- A folded run is a button, "12 unchanged lines"; opening it keeps focus in the diff.
- The view is a segmented control and wrap a toggle button, each named. Copy announces its result, and a refused clipboard says so.
- On a right-to-left page the header follows the page while the code stays left to right, as code does.

</ReferenceRow>
