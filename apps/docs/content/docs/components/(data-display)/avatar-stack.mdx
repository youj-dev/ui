## Installation & usage

<InstallTabs name="avatar-stack" noImport />

Use an avatar stack to show who is in a document, a project or a call, when the faces matter more than the details. It shows the first `max` people and puts everyone else behind a "+N" button that opens the full list with each person's role and status. For a single person, use an [Avatar](/docs/components/avatar). For a list people manage (roles, removal), use a table or a list, not a stack.

```tsx
import { AvatarStack, type AvatarStackUser } from '@youj/react'

const people: AvatarStackUser[] = [
  { id: 'mira', name: 'Mira Chen', src: '/avatars/mira.jpg', presence: 'online', description: 'Design lead' },
  { id: 'jonas', name: 'Jonas Weber', presence: 'away' },
  // …
]

export function Collaborators() {
  return <AvatarStack users={people} label="Collaborators" />
}
```

Each person needs an `id` and a `name`. Without a `src`, the avatar shows their initials. `presence` adds a status dot (`online`, `away`, `busy` or `offline`), and `description` is the second line in the full list. `label` names the group ("Collaborators: Mira Chen, Jonas Weber and 5 others") and heads the list.

On a card, set the rings that cut the overlaps out to the card's color, as the demo does: `*:data-[slot=avatar]:ring-surface`.

#### Reduced motion

The stack doesn't fan out on hover, the hovered avatar doesn't lift and status dots appear in place. Tooltips and the list still open, with the overlay presets' reduced behavior.

<ReferenceRow title="Accessibility" summary="Keyboard, announcements">

### Accessibility

- The stack is a `group` named with everyone in it: the first two names and a count of the rest.
- Each avatar shows the person's name and status in a tooltip on hover. Avatars aren't in the tab order, so keyboard and screen reader users get the names from the group's label and the "+N" list.
- "+N" is a button named "Show all 7 collaborators". It opens the list in a Popover, where each status is written out, not only shown as a color.
- Presence dots are decorative; the status text is in the tooltip and the list.
