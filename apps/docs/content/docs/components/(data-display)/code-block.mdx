<Story id="languages" label="Languages">

<ComponentPreview name="code-block/languages" height={380} />

Three blocks: a shell command, a diff and a JSON file.

Highlighting is a small built-in tokenizer: TypeScript and JavaScript (with JSX), C-like languages (Go, Rust, Java, C#, Swift, Kotlin, PHP), Python, Ruby, shell, JSON, CSS, HTML and XML, SQL, YAML and diffs. Anything else shows as plain text. It produces tokens, never HTML, so code from a user or a model can't inject markup. The colors are theme tokens, so they follow the theme in both modes.

</Story>

## Installation & usage

<InstallTabs name="code-block" noImport />

Use a code block to show code someone will read or copy: an install command, a config file, a snippet in a changelog or an empty state. It's the same block the [Chat](/docs/components/chat) renders for fenced code in a model's answer. For code inside a sentence, use [Typography](/docs/components/typography)'s `TypographyInlineCode`.

```tsx
import { CodeBlock } from '@youj/react'

export function InstallCommand() {
  return <CodeBlock code="pnpm dlx @youj/cli@latest init" language="sh" />
}
```

The header shows `filename` when you pass one, with the `language` value beside it as written (`ts`, `sh`), or else that value alone, or `text`. Long lines scroll sideways instead of wrapping, so indentation stays true; the scrollbar appears only when it's needed. `lineNumbers` adds a gutter that holds still while the code scrolls.

<ReferenceRow title="Accessibility" summary="Keyboard, ARIA, announcements">

### Accessibility

- The block is a `figure` whose `figcaption` holds the file name or language and the copy button.
- The code sits in a scroll region named by the file name, or "TypeScript code" and so on, so a keyboard user can scroll a long line.
- The copy button is named by `copyLabel`. Its tooltip says "Copied" after a copy, and the result is announced politely. A clipboard that refuses (no permission, an insecure page) is announced as "Couldn’t copy", not faked.
- Line numbers are decorative (`aria-hidden`) and can't be selected, so copying by hand takes only the code.

</ReferenceRow>
