## Installation & usage

<InstallTabs name="capsule-toggle" noImport />

Use a capsule toggle for a small choice that sits with other floating controls: a monitor source, a layout, a snap setting. It's a [Segmented Control](/docs/components/segmented-control) that uses the capsule as its track, so the selected option glides inside the pill. For more than three options, use a Segmented Control or [Tabs](/docs/components/tabs).

```tsx
import { CapsuleToggle } from '@youj/react'

<CapsuleToggle
  label="Monitor"
  value={monitor}
  onValueChange={setMonitor}
  options={[
    { value: 'source', label: 'Source' },
    { value: 'mix', label: 'Mix' },
    { value: 'master', label: 'Master' },
  ]}
/>
```

`label` puts a short name in front of the options. `iconOnly` shows only each option's `icon`, and its label becomes the option's name.

</Example>

<ReferenceRow title="Accessibility" summary="Keyboard, ARIA">

### Accessibility

- It's a group named by `label` or `aria-label`, with one tab stop. The arrow keys move between options.
- One option is always selected, and each option says whether it's pressed.
- With sound on, a new choice plays `select`. `sound={false}` turns it off.
