Three pills: a live CPU load with a trend line, a latency that fell by 6 ms, and a cache that grew by 0.3 GB.

`delta` is the change since the last reading. `better` says which way is good, so the change is tinted to match. The default is `up`. Use `down` for latency and errors, and `none` for figures such as loudness, where a change is just news and stays neutral.

## Installation & usage

<InstallTabs name="stat-pill" noImport />

Use a stat pill for a figure people glance at while they work: the CPU load in an editor, the latency of a stream, the size of a cache. It shows an icon, the figure's name, the value with its unit, and optionally how it's moving, either a change since the last reading or a small trend line.

```tsx
import { StatPill } from '@youj/react'
import { ActivityIcon } from '@youj/icons'

<StatPill label="Latency" icon={<ActivityIcon />} value={42} unit="ms" delta={-6} better="down" />
```

`format` takes `Intl.NumberFormat` options for the value. Without it, the value keeps its own decimals. `trend` takes recent readings, oldest first, and draws them as a small line with a dot on the latest one.

</Example>

<ReferenceRow title="Accessibility" summary="announcements">

### Accessibility

- The name, value and unit are plain text, so they're read in order.
- The direction of a change is spoken ("Up 4.2"), so it isn't carried by color alone.
- The icon and the trend line are decorative.
- If the figure updates often, don't make it a live region; people can read it when they want.
