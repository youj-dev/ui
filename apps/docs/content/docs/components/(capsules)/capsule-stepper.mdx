## Installation & usage

<InstallTabs name="capsule-stepper" noImport />

Use a capsule stepper for a number people adjust in small steps rather than type: a tempo, a zoom level, a count of takes. You can still click the number and type one.

```tsx
import { CapsuleStepper } from '@youj/react'

<CapsuleStepper label="Tempo" defaultValue={124} min={60} max={200} unit="BPM" />
```

It's built on Base UI's number field, like [Number Input](/docs/components/number-input). Values are read and written for the locale, kept between `min` and `max`, and step by `step`. Shift with an arrow key steps by `largeStep`. Holding a button keeps stepping, and a button turns off at its end of the range. `format` takes `Intl.NumberFormat` options, such as `{ style: 'percent' }`.

### Accessibility

- `label` names the field. Without one, use `aria-label`.
- `unit` is read after the value.
- The buttons are named "Increase" and "Decrease" by the labels, which the language packs translate.
