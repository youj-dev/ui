A `SpotlightCard` outside a grid tracks the pointer by itself. Its light stays inside it, and its neighbors stay dark. Use standalone cards when they sit apart, like metrics in a row, and a grid when they read as one set.

`radius` sets the size of the light in pixels, 260 by default. Use a smaller light on smaller cards, as the metric cards in the preview do with 180, so the glow stays a highlight rather than a wash.

## Installation & usage

<InstallTabs name="spotlight-card" noImport />

Use it for a grid of choices people scan with the pointer: integrations, templates, plans. The light tells them where they are, and the shared glow along neighboring edges makes the grid feel like one surface. Keep it off dense dashboards, where every card is read rather than chosen. `SpotlightCard` is the [Spotlight](/docs/components/spotlight) effect with a card look, so reach for the effect when you need your own look.

`SpotlightGrid` lays out its cards and shares one light across them. It's a CSS grid, so add your own columns and gaps.

```tsx
import { SpotlightCard, SpotlightGrid } from '@youj/motion/interactions'

export function Integrations({ items }: { items: Integration[] }) {
  return (
    <SpotlightGrid className="grid-cols-3 gap-3">
      {items.map((item) => (
        <SpotlightCard key={item.slug}>
          <a href={`/integrations/${item.slug}`} className="block h-full rounded-xl p-4">
            {item.name}
          </a>
        </SpotlightCard>
      ))}
    </SpotlightGrid>
  )
}
```

A card brings the look: a 12px radius, a hairline border and the surface color. Pass `className` to change any of it. When the whole card is one link or button, put the control inside the card and let it fill the card, as the demo does, so the card and its target are the same size.

</Example>

<ReferenceRow title="Keyboard" summary="Tab through the grid">

### Keyboard

Tab through the grid in the demo. Keyboard focus parks the light at the center of the focused card, and moving focus to the next card glides it across. Touch doesn't move the light.

</ReferenceRow>

#### Reduced motion

The light doesn't follow the pointer. The card under the pointer, or the one holding keyboard focus, shows a static accent border, so the grid still marks where the reader is, without movement.

</ReferenceRow>

<ReferenceRow title="Accessibility" summary="Keyboard, ARIA, focus">

### Accessibility

- The light's layers are `aria-hidden`, and the cards add no roles or tab stops. Put the link or button inside the card, and give it a visible focus ring.
- Keyboard focus lights the focused card just as the pointer does, so the effect is never pointer-only.
- The glow is decoration. Say what the card is, and whether it's installed or selected, in its content.

</ReferenceRow>
