Inputs in their hover, focus, invalid, disabled and read-only states.

At rest the field is the theme's: a soft filled band with no border by default, or its fill on a 3:1 border where the theme's `fields` are `outlined`. Hover deepens the band (or strengthens the border). Focus turns the edge accent inside a soft 3px halo, so the field reads as lit rather than outlined. Invalid swaps both to the destructive color. Disabled and read-only are native, and read-only gets a muted fill so it doesn't look editable.

Set `aria-invalid` yourself on a standalone input. Inside a Field, `invalid` sets it for you.

</Story>

`onValueChange` hands you the new string, and the `value` you pass back is what the input shows. Use it to format as people type. The standard `onChange` event works too.

## Installation & usage

<InstallTabs name="input" noImport />

Use Input for short text such as a name, email address or URL. Choose a [Textarea](/docs/components/textarea) for multiple lines, an [Input Group](/docs/components/input-group) for a prefix, icon or button inside the field, or a [Select](/docs/components/select) for a known list of answers.

```tsx
import { Field, FieldLabel, Input } from '@youj/react'

export function DisplayName() {
  return (
    <Field>
      <FieldLabel>Display name</FieldLabel>
      <Input name="displayName" autoComplete="name" />
    </Field>
  )
}
```

Inside a [Field](/docs/components/field), the input is labeled, described and validated with no extra wiring, and it takes `required` from the Field. On its own, name it with `aria-label` or a [Label](/docs/components/field#label).

</Example>

#### Reduced motion

The input doesn't move. Its border, fill and halo change color on the `fast` token with or without reduced motion.

<ReferenceRow title="Accessibility" summary="Keyboard, ARIA, focus">

### Accessibility

- It's a native `<input>`. Give it a visible label through a Field, or an `aria-label` when the context names it, like a search box.
- Focus shows as an accent border and halo. A transparent outline rides along, so Windows high-contrast mode still draws a focus indicator.
- Text is 13px, and 16px on touch screens, so iOS doesn't zoom the page when the input takes focus.
- Pick the right `type`, `inputMode` and `autoComplete`. They choose the on-screen keyboard and let browsers and password managers fill the field.

</ReferenceRow>
