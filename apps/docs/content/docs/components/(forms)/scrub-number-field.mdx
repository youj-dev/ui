## Installation & usage

<InstallTabs name="scrub-number-field" noImport />

Use a scrub number field where people tune a number by feel and want the exact value too: a position, a blur, a rotation, an opacity. For a quantity entered in a form, with steppers and locale formatting, use a [Number Input](/docs/components/number-input); for a value on a visible range, a [Slider](/docs/components/slider).

```tsx
import { useState } from 'react'
import { ScrubNumberField } from '@youj/react'

export function Blur() {
  const [blur, setBlur] = useState(24)
  return <ScrubNumberField aria-label="Blur" label="B" unit="px" min={0} max={100} value={blur} onValueChange={setBlur} />
}
```

The value is a `number`. Typed text commits on Enter or blur and is clamped but not snapped to the step, so `12.5` stays `12.5`; text that isn't a number is put back. Both `.` and `,` are read as a decimal separator.

</Example>

#### Data attributes

The root carries `data-slot="scrub-number-field"` and `data-size` (`sm` or `default`), plus `data-yj-scrubbing` while the handle is being dragged. The handle is `scrub-number-field-handle` in `data-slot`.

</ReferenceRow>

<ReferenceRow title="Accessibility" summary="Spinbutton, keys, value text">

### Accessibility

- The field is an input with `role="spinbutton"` and `aria-valuenow`, `aria-valuemin`, `aria-valuemax` and an `aria-valuetext` that reads the value with its unit ("24 px"). Name it with `aria-label` or `aria-labelledby`; the handle is hidden from assistive technology.
- ArrowUp and ArrowDown step by `step`, with Shift ×10 and Alt ×0.1. PageUp and PageDown step by `largeStep` (default ten steps). Home and End go to `min` and `max`.
- Dragging is an extra for pointer users: everything it does is available from the keyboard.
- The mouse wheel never changes the value, so a scrolling page doesn't edit a form.
- Nothing animates, so there is no reduced motion to honor; a drag changes the value directly.

</ReferenceRow>
