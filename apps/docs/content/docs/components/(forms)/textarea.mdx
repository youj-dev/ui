It starts three lines tall and grows with its content up to 16rem, then scrolls. Growth is CSS `field-sizing: content`. In browsers without it, the box keeps its starting height and you can drag it taller. Border, hover, focus and invalid match Input.

## Installation & usage

<InstallTabs name="textarea" noImport />

Use Textarea for comments, feedback, descriptions and other multi-line text. Use an [Input](/docs/components/input) for a single line. Wrap the textarea in an [Input Group](/docs/components/input-group) when you need a toolbar or send button inside its frame.

```tsx
import { Field, FieldDescription, FieldLabel, Textarea } from '@youj/react'

export function ProjectDescription() {
  return (
    <Field>
      <FieldLabel>Description</FieldLabel>
      <Textarea name="description" placeholder="What does this project do?" />
      <FieldDescription>Shown on the project page and in search.</FieldDescription>
    </Field>
  )
}
```

It renders a real `<textarea>` through Base UI's field control, so inside a [Field](/docs/components/field) it's labeled, described, validated and made `required` exactly like an Input. `rows`, `cols` and `wrap` go to the element.

</Example>

<ReferenceRow title="Props" summary="value, defaultValue (2)">

### Props

<PropsTable name="Textarea" />

`value` and `defaultValue` take strings. Every other native textarea attribute passes through, including `onChange`, `rows` and `maxLength`.

</ReferenceRow>

#### Reduced motion

The textarea doesn't animate. It grows line by line as you type, with or without reduced motion.

<ReferenceRow title="Accessibility" summary="Keyboard, ARIA, focus">

### Accessibility

- It's a native `<textarea>`: `Enter` adds a new line and `Tab` moves focus on.
- Label it through a Field, or with `aria-label` when the context names it.
- If you use `maxLength`, say so in the description. The browser stops accepting input silently, which reads as a broken keyboard.
- Text is 16px on touch screens, so iOS doesn't zoom the page on focus.

</ReferenceRow>
