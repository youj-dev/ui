## Installation & usage

<InstallTabs name="switch" noImport />

Use Switch for settings that apply immediately, such as muting a channel or turning on previews. For a value saved with a form, use a [Checkbox](/docs/components/checkbox). For named alternatives such as light and dark, use a [Toggle Group](/docs/components/toggle-group) or [Radio Group](/docs/components/radio-group).

```tsx
import { Field, FieldLabel, Switch } from '@youj/react'

export function AirplaneMode() {
  return (
    <Field orientation="horizontal">
      <Switch />
      <FieldLabel>Airplane mode</FieldLabel>
    </Field>
  )
}
```

In a settings row, put the label and its description in a `FieldContent` first and the switch last, so the label leads and the control lines up at the end of every row.

</Example>

### Motion

The spring drives a single value from 0 to 1, and CSS turns it into the thumb's translate. A switch flipped back mid-flight retargets the spring from where the thumb is, so rapid toggling never jumps.

#### Liquid

<MotionSpec
  rows={[
    { moment: 'Droplet travel', note: 'overshoots its end and settles', spring: 'settle' },
    { moment: 'Stretch', note: 'up to 30% wider and 18% flatter with the spring’s speed, squashed against the end while it overshoots', spring: 'settle' },
    { moment: 'Fill', note: 'the accent, clipped to the traveled part of the track, follows the same value', spring: 'settle' },

The liquid switch springs on `settle`, the kit's one spring that overshoots, so the droplet lands with a small wobble. Its stretch is read from the spring's speed, so a rapid toggle that retargets mid-flight stretches it the right amount.

#### Reduced motion

The thumb moves to its end at once and the press doesn't squeeze it. The thumb's position and the track color still show the state. The liquid droplet does the same: no stretch, no swell, and the fill shows at once.

<ReferenceRow title="Accessibility" summary="Keyboard, ARIA">

### Accessibility

- It's a `switch` role with `aria-checked`. `Space` toggles it.
- A `FieldLabel` in the same `Field` names it. Outside a `Field`, give it `aria-label`, or pair `Label htmlFor` with the switch's `id`.
- In both states the thumb clears 3:1 against the track, and the track clears 3:1 against the page. The liquid droplet is a near-white glass on the same off track and the accent fill. The thumb's side shows the state too, so it doesn't rest on color alone.
- The hit area extends past the track, and grows on touch screens.

</ReferenceRow>
