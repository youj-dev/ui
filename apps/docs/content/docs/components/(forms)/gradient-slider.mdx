The same slider in each tone.

The gradient comes from your theme, so it changes with it. Pick it with `tone`:

- `spectrum`, the default, uses the theme's chart colors from cool to warm. It suggests nothing good or bad, so it suits a preference such as creativity. In a theme without chart colors, it runs from gray to the accent.
- `accent` runs the accent from faint to full.
- `status` runs from success through warning to danger. Use it only when the far end really is a risk, such as how much work goes unchecked. On a scale like creativity, a red end would tell people that high values are wrong.

## Installation & usage

<InstallTabs name="gradient-slider" noImport />

Use a gradient slider when a value is a feel rather than a number: how freely a model writes, how warm a light is, how strong an effect is. The track is a color gradient, lit up to the thumb. The thumb shows the exact value, and named zones under the track say which stretch you're in, such as "Literal", "Balanced" or "Exploratory".

```tsx
import { GradientSlider } from '@youj/react'

<GradientSlider
  label="Creativity"
  value={creativity}
  onValueChange={setCreativity}
  min={0}
  max={1.5}
  step={0.05}
  zones={[{ label: 'Literal', to: 0.4 }, { label: 'Balanced', to: 0.95 }, { label: 'Exploratory' }]}
/>
```

Each zone runs up to its `to` value, and the last one runs to `max`. `ticks` sets how many divisions the ruler under the track shows, and zone edges get longer ticks. `format` takes `Intl.NumberFormat` options for the value. Use `onValueCommitted` for work that should wait until the thumb is let go, like a save.

</Example>

<ReferenceRow title="Accessibility" summary="Keyboard, ARIA">

### Accessibility

- `label` names the thumb. Without one, use `aria-label`.
- The value is spoken with its zone ("0.65, Balanced"). The wording comes from the labels' `gradientSliderValue`, which the language packs translate.
- The arrow keys step. Page Up, Page Down and Shift with an arrow take large steps, and Home and End jump to the ends.
- In a right-to-left page the scale runs from the right, and the arrow keys follow.
- With sound on, crossing into another zone plays `tick`. `sound={false}` turns it off.

</ReferenceRow>
