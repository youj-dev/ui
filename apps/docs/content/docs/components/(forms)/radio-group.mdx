## Installation & usage

<InstallTabs name="radio-group" noImport />

Use Radio Group when people need to choose one option and see the full list. Use a [Select](/docs/components/select) for longer lists, [Checkboxes](/docs/components/checkbox) for choices that can combine, or a [Toggle Group](/docs/components/toggle-group) for view settings.

Each `RadioGroupItem` sits in its own `Field` with a `FieldLabel`. Name the group with a `FieldSet` and `FieldLegend`, or with `aria-label` on the `RadioGroup`.

```tsx
import { Field, FieldLabel, FieldLegend, FieldSet, RadioGroup, RadioGroupItem } from '@youj/react'

export function Density() {
  return (
    <FieldSet>
      <FieldLegend variant="label">Density</FieldLegend>
      <RadioGroup defaultValue="comfortable" name="density">
        <Field orientation="horizontal">
          <RadioGroupItem value="comfortable" />
          <FieldLabel>Comfortable</FieldLabel>
        </Field>
        <Field orientation="horizontal">
          <RadioGroupItem value="compact" />
          <FieldLabel>Compact</FieldLabel>
        </Field>
      </RadioGroup>
    </FieldSet>
  )
}
```

`defaultValue` makes it uncontrolled. Pass `value` and `onValueChange` to own the choice, and `name` to submit it with a form.

#### RadioGroupItem

<PropsTable name="RadioGroupItem" />

The group takes Base UI's `value`, `defaultValue`, `onValueChange`, `name`, `disabled`, `readOnly` and `required`. Each item takes a `value`, plus its own `disabled`.

The dot is a CSS transition, so a choice that changes mid-way picks up from the dot's current scale.

#### Reduced motion

The dot switches on and off without growing, and the press doesn't squeeze. The chosen option still shows the filled ring and the dot, so the choice reads the same.

<ReferenceRow title="Accessibility" summary="Keyboard, ARIA, focus">

### Accessibility

- The group is one tab stop. `Tab` lands on the chosen option, the arrow keys move the choice and wrap at the ends, and `Space` selects the focused option.
- The group is a `radiogroup`, named by its `FieldLegend` or `aria-label`. Each item is a `radio`, named by its `FieldLabel`.
- `required` on the group or its `Field` makes a choice mandatory before the form submits.
- Each 16px radio has a 24px hit area, and 40px on touch screens.

</ReferenceRow>
