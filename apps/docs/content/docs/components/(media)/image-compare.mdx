## Installation & usage

<InstallTabs name="image-compare" noImport />

Use an Image Compare to show what changed between two versions of the same picture: an edit, a redesign, a model's output against its input, a site before and after a fix. For pictures to step through one at a time, use a [Carousel](/docs/components/carousel).

```tsx
import { ImageCompare } from '@youj/react'

<ImageCompare
  before={{ src: '/room-before.jpg', alt: 'The room before the renovation' }}
  after={{ src: '/room-after.jpg', alt: 'The room after the renovation' }}
  beforeLabel="Before"
  afterLabel="After"
  className="aspect-video"
/>
```

`before` and `after` take `{ src, alt }` for an image (drawn cover-fit) or any node: an illustration, a canvas, a rendered component. `after` sits underneath and sets the size; `before` is cut off at the divider. Give both the same aspect, or set one on the component with `className`.

The position is a number from 0 to 100: how much of `before` shows. It is uncontrolled with `defaultValue` (50), or controlled with `value` and `onValueChange`.

### Props

<PropsTable name="ImageCompare" />

#### Data attributes

The root carries `data-orientation` (`horizontal` or `vertical`), plus `data-dragging` while a pointer holds it and `data-disabled` when disabled. Its parts are `image-compare-before`, `image-compare-after`, `image-compare-divider`, `image-compare-handle` and `image-compare-label` (with `data-side`). The drawn position is `--ui--compare`, from 0 to 100.

</ReferenceRow>

#### Reduced motion

Dragging works the same. Presses, keys and new values move the divider at once, and the handle and tags change without easing.

<ReferenceRow title="Accessibility" summary="Slider role, keyboard, value text">

### Accessibility

- The handle is a `slider` (0 to 100) with `aria-orientation`, named "Comparison divider". Its value text says how much of each side shows ("Before 60%, After 40%"), using `beforeLabel` and `afterLabel` when they are strings.
- Arrow keys step by 5 and Page Up and Page Down by 20; Home and End go to either end. Keys move the divider the way it looks: right (left in right-to-left) or down is up the scale.
- A press anywhere on the picture moves focus to the handle, so the keys carry on from there. The handle has a visible focus ring.
- Touch drags along the divider's axis and still scrolls the page across it. Each pointer is captured, so a drag keeps going outside the picture.
- Give each `{ src, alt }` image an `alt` that says what is different about it. `disabled` takes the handle out of the tab order and sets `aria-disabled`.

</ReferenceRow>
