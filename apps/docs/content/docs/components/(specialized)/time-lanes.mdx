## Installation & usage

<InstallTabs name="time-lanes" noImport />

Use time lanes for any rotation where the question is who holds it when: on-call pagers, support shifts, a release captain. There's a lane per person or team, each shift a bar from its start to its end, an override hatched over the lane of whoever covers, a dashed baton where one lane hands off to another, and now as a line in the accent. For events that already happened, use a [Timeline](/docs/components/timeline); for jobs that run on a daily clock, a [Day Ring](/docs/components/day-ring).

```tsx
import { TimeLanes, type RotaLane, type RotaShift } from '@youj/react'

const lanes: RotaLane[] = [
  { id: 'mara', name: 'Mara Quinn', detail: 'Platform' },
  { id: 'theo', name: 'Theo Park', detail: 'Platform' },
]
const shifts: RotaShift[] = [
  { id: 'a', lane: 'mara', start: new Date('2026-09-28T09:00'), end: new Date('2026-09-29T09:00') },
  { id: 'b', lane: 'theo', start: new Date('2026-09-29T09:00'), end: new Date('2026-09-30T09:00') },
  { id: 'c', lane: 'theo', start: new Date('2026-09-28T13:00'), end: new Date('2026-09-28T17:00'), override: true, note: 'Covering Mara' },
]

<TimeLanes lanes={lanes} shifts={shifts} start={new Date('2026-09-28T00:00')} />
```

`start` is the first moment shown (usually a Monday at midnight) and `days` how many follow (7 by default). A shift sits in its `lane` from `start` to `end`; `override` draws it hatched above the lane, and `note` adds a line to its detail. Lanes take the chart colors in turn, or their own `tone`. Where one lane's shift ends as another lane's begins, a dashed baton joins them, with a diamond on the day axis.

`now` places the line: by default it follows the clock, read every 30 seconds once the page is live (on the server there's no line until the browser has the time); pass a time to pin it, or `null` to hide it. Shifts that ended fade and the one on call now is lit. `renderDetail` adds your own actions to a shift's detail: Swap, Page, a link to the schedule.

### Accessibility

- The rota is a group named by `label` (default: the labels' "On-call rota") and described by how to move through it; each lane is a group named by its person or team.
- Each shift is a button named by its label, who, from and until when, whether it's an override and whether it's proposed ("4935, Iris Okafor, Mon 10:30 to Mon 13:00, Proposed").
- The shifts are one tab stop, starting on the shift on call now. Left and right move along a lane (mirrored in RTL), up and down to the nearest shift in the next lane, Home and End to a lane's ends, and Enter or Space opens the detail.
- The detail says when, for how long, whether it's an override, who takes over, and whether the shift is on call now, upcoming or ended.
- Its words come from the labels (`rota`, `rotaShift`, `rotaHint`, `rotaHandoff`, `rotaOverride`, `rotaOnCall`, `rotaUpcoming`, `rotaEnded`, `proposed`), translated by the language packs.
