## Installation & usage

<InstallTabs name="rollout-ruler" noImport />

Use a rollout ruler to show and set how far a feature has rolled out: internal, beta, 10%, 50%, GA. The track is cut into its stages, each an equal stretch, so the early cohorts get as much room as the late ones; the axis under it says what each gate is worth. For a free percentage, use a [Slider](/docs/components/slider).

```tsx
import { RolloutRuler } from '@youj/react'

const [share, setShare] = useState(10)

<RolloutRuler label="Rolled out to" value={share} onValueChange={setShare} />
```

`value` is the share of users, 0–100, and while it's interactive it's always a stage's value (or 0). The default stages are Internal 1%, Beta 5%, 10%, 50% and GA 100%; pass `stages` for your own, in any order:

```tsx
<RolloutRuler
  stages={[
    { value: 0.5, label: 'Canary' },
    { value: 2, label: 'Staff' },
    { value: 25, label: '25%' },
    { value: 100, label: 'All' },
  ]}
/>
```

Ticks already rolled out light in `tone` (the accent), the stretch to the next gate is a runway at a third of it, and the gate the value sits on names itself in the tone. A kill switch is a change from outside: set `value` to 0 (with `tone="danger"`) and the ruler sweeps back tick by tick.

<ReferenceRow title="Accessibility" summary="Keyboard">

### Accessibility

- Interactive, it's a slider over the stages, named by `label` (or the labels' "Rollout"). Its value is spoken with the stage's name: "Beta at 5%", "50%", "Off".
- The arrow keys and Page keys step one gate; Home and End go to off and the last stage. A press anywhere on the ruler moves to the nearest gate.
- `readOnly` and `size="sm"` are meters with the same spoken value.
- Its built-in text (the default stage names, "Off") comes from the labels, so `<YoujProvider labels>` translates it.

</ReferenceRow>
