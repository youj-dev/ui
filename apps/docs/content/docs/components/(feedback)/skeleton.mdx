A Members list that loads for about two seconds and resolves into content; Reload runs it again.

Pair skeletons with motion's [Content Swap](/docs/motion/content-swap), as the demo does. The skeleton drops away quickly, the content resolves into focus a step later, and the box morphs between the two heights, so the page below moves instead of jumping. ContentSwap also marks the region `aria-busy` and announces the wait once. Press Reload to watch it go both ways.

```tsx
import { ContentSwap } from '@youj/motion'

<ContentSwap loading={isLoading} fallback={<MembersSkeleton />} loadingLabel="Loading members">
  <MemberList members={data} />
</ContentSwap>
```

## Installation & usage

<InstallTabs name="skeleton" noImport />

Use Skeleton when you know the shape of the loading content, such as rows, a profile or a card. Use a [Spinner](/docs/components/spinner) for short waits without a known layout, or [Progress](/docs/components/progress) for measurable work.

A skeleton is a block. Size and round it with classes to match the content it stands in for.

```tsx
import { Skeleton } from '@youj/react'

export function ProfileSkeleton() {
  return (
    <div className="flex items-center gap-3">
      <Skeleton className="size-10 rounded-full" />
      <div className="grid flex-1 gap-2">
        <Skeleton className="h-3.5 w-3/5" />
        <Skeleton className="h-3 w-2/5" />
      </div>
    </div>
  )
}
```

</Example>

### Motion

<MotionSpec
  rows={[
    { moment: 'Shimmer', note: 'a band of light crosses in the first 60% of each cycle, then rests', duration: 'deliberate', ease: 'standard', value: '× 3 per cycle' },
  ]}
  reduced="The band is gone and the blocks hold still."
/>

The cycle is three `deliberate` beats, so the band reads as a calm pulse rather than a constant wash. It follows the Speed control, and it runs the other way under right-to-left.

#### Reduced motion

The traveling band is removed and each block is a still, recessed shape. The layout still shows where content will land.

<ReferenceRow title="Accessibility" summary="ARIA, announcements">

### Accessibility

- Skeletons are `aria-hidden`: a pile of empty blocks means nothing to a screen reader.
- Put `aria-busy` on the region they stand in for, and announce the wait once in a polite status, such as "Loading members". ContentSwap does both with `loadingLabel`.
- Don't leave skeletons up once the content has failed. Swap them for an error with a way to retry.

</ReferenceRow>
