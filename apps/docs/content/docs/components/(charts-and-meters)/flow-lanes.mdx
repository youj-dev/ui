## Installation & usage

<InstallTabs name="flow-lanes" noImport />

Use flow lanes for one stream split many ways, where the split is the story: a model router's traffic by model, a load balancer's pools, a queue's consumers, an inbox's routing rules. The [Routing flow](/docs/blocks/flows#routing-flow) card is built on it. For a run of steps with branches use a [Flow Graph](/docs/components/flow-graph); for shares without a source, a [Share Bar](/docs/components/share-bar).

```tsx
import { FlowLanes } from '@youj/react'

<FlowLanes
  source="Gateway"
  label="Requests by model"
  lanes={[
    { id: 'pro', label: 'Kestrel 3 Pro', value: 47, tone: 'chart-1' },
    { id: 'orrery', label: 'Orrery 2', value: 137, tone: 'chart-2' },
  ]}
  formatValue={(v) => `${Math.round(v)}/s`}
/>
```

`source` names the node the lanes leave from. Each lane's `value` is its rate in any unit: it sets how many particles ride it (a share of the whole, at least one for any flow), the weight of its line and the share spoken with it. Lanes take the chart colors in order unless they set a `tone`. `formatValue` writes a rate with its unit. The particles stop while the chart is off screen or the tab is hidden, and `paused` stops them for good. No lanes, or nothing flowing, shows the empty state.

The lanes are drawn in place and the particles stand still on them, as many as the rate gives, so a busy lane still looks busy.

<ReferenceRow title="Accessibility" summary="Keyboard, focus, screen readers">

### Accessibility

- A named `group` (your `label`, or the labels' "Flow lanes") described by the source, how many lanes it feeds and their total ("Gateway to 4 lanes, 312/s in all.").
- The lanes are a list; each is read with its name, rate and share ("Orrery 2: 137/s, 44%").
- The names are one tab stop. The arrow keys, `Home` and `End` move between them, and focus lights the lane as pointing does.
- The drawing and the particles are decorative; the list says the same in words. Color is never the only cue: every lane is named.
- Its built-in text comes from the labels, so `<YoujProvider labels>` translates it.

</ReferenceRow>
