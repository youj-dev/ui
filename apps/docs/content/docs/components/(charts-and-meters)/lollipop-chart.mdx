## Installation & usage

<InstallTabs name="lollipop-chart" noImport />

Use a lollipop chart to compare many items on one measure where the sign matters, like error budget left by SLO, score against par by team, or stock against target by shop. A table beside it can follow and lead the pick. For a few items' parts of a whole use a [Share Bar](/docs/components/share-bar); for values over time, a [Chart](/docs/components/chart). The [Lollipop ranking](/docs/blocks/rankings-and-breakdowns#lollipop-ranking) card is built on it.

```tsx
import { LollipopChart } from '@youj/react'

<LollipopChart
  label="Budget left by SLO"
  data={slos.map((s) => ({ id: s.id, label: s.name, value: s.budget, tone: s.budget < 0 ? 'danger' : 'success' }))}
  sort="ascending"
  domain={[-1, 1]}
  value={picked}
  onValueChange={setPicked}
  formatValue={(v) => percent.format(v)}
/>
```

Each item is a dot at its `value` on a stem from `baseline` (0 by default), in its `tone`. `sort` orders them lowest or highest first; without it they keep the data's order. The scale runs over `domain` (by default the data's range with the baseline, rounded out to even `ticks`). `formatValue` writes values in the tooltip, the pill and the spoken text, and `formatTick` the axis. Give it a height with a class (`h-64` by default). No items shows the empty state.

<ReferenceRow title="Accessibility" summary="Keyboard, focus, screen readers">

### Accessibility

- A named `listbox` (your `label`, or the labels' "Lollipop chart") described by the count and the range ("18 points, from -82.3% to +94.1%.").
- Every item is an `option` named with its label and value, `aria-selected` when picked.
- One tab stop. The arrow keys walk the items (mirrored in RTL), `Home` and `End` go to the ends, and `Enter` or `Space` picks; focus shows the same tooltip as hovering.
- The axis, gridlines and stems are decorative. Tones never carry the meaning alone: the values are signed and spoken.
- Its built-in text comes from the labels, so `<YoujProvider labels>` translates it.

</ReferenceRow>
