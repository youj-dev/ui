## Installation & usage

<InstallTabs name="unit-chart" noImport />

Use a unit chart when the counts are small enough to see one by one and that matters: covers through a service, tickets by hour, signups by day. Each column is a bucket and each dot one unit, stacked from the baseline over a faint grid of every dot the chart could hold, so the empty room reads as part of the scale. For larger values, or a trend with tooltips on several series, use a [Chart](/docs/components/chart); for a distribution someone filters, a [Histogram Range](/docs/components/histogram-range).

```tsx
import { UnitChart } from '@youj/react'

<UnitChart
  label="Covers through the day"
  data={[
    { label: '11:30', value: 3 },
    { label: '11:45', value: 6 },
    { label: '12:00', value: 9 },
  ]}
  highlight={[1, 2]}
  formatValue={(v) => `${v} covers`}
/>
```

The grid is as tall as the peak with some headroom; pass `rows` to keep the scale still when the data changes. Labels sit under about six columns; `tickEvery` sets the step. `highlight` takes the first and last index of a range to keep in the tone, and the rest go quiet.

</Example>

### Styling

Parts: `unit-chart`, `unit-chart-plot`, `unit-chart-columns`, `unit-chart-column`, `unit-chart-dots`, `unit-chart-dot`, `unit-chart-axis`, `unit-chart-tick`, `unit-chart-summary`, `unit-chart-tooltip` and `unit-chart-empty`. Each dot has `data-state` (`on` or `off`); a column inside the `highlight` range has `data-highlighted`. The root sets `--unit-chart-tone`, the lit dots' color, and `--unit-chart-off`, the empty ones'.

<ReferenceRow title="Accessibility" summary="Keyboard, focus">

### Accessibility

- A named `group` (your `label`, or the labels' "Unit chart") holding a `list` of the columns. Each is named with its label and value, and whether it's highlighted ("19:00: 19 covers, highlighted").
- A summary describes the group: how many columns, the total and the peak.
- One tab stop. The arrow keys walk the columns in the order they're drawn, in either text direction; Home and End go to the first and last. Focus shows the tooltip, as hover does.
- The dots and the axis are decorative; everything they show is in the names.
- Its built-in text comes from the labels, so `<YoujProvider labels>` translates it.

</ReferenceRow>
