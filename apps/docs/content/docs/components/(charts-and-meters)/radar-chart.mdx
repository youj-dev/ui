## Installation & usage

<InstallTabs name="radar-chart" noImport />

Use a radar chart to compare a handful of things on the same few measures, when the overall shape matters more than any one number: models, plans, candidates, products. Keep it to three to eight axes and a few series. For one thing over time use a [Sparkline](/docs/components/sparkline); for exact values side by side, a table; the [Compare items](/docs/blocks/trends-and-comparisons) card pairs this chart with an overview table.

```tsx
import { RadarChart } from '@youj/react'

<RadarChart
  label="Assistants compared"
  axes={[
    { id: 'reasoning', label: 'Reasoning', description: 'How well it works through multi-step problems.' },
    { id: 'speed', label: 'Speed' },
    { id: 'safety', label: 'Safety' },
  ]}
  series={[
    { id: 'atlas', name: 'Atlas 2', values: [88, 56, 80] },
    { id: 'quill', name: 'Quill S', values: [64, 92, 72] },
  ]}
/>
```

`axes` are drawn clockwise from the top, and each series gives one value per axis in the same order. The scale runs from zero at the center to `max` at the outer ring (by default the largest value rounded up to a round number; pass one to keep the scale still as data changes), divided by `rings`. Series take the chart colors in order unless they set a `tone`. `formatValue` writes values with their unit, and `legendEnd` adds your own controls beside the legend. Fewer than three axes, or no series, shows the empty state.

<ReferenceRow title="Accessibility" summary="Keyboard, focus, screen readers">

### Accessibility

- A named `group` (your `label`, or the labels' "Radar chart"). Every point is an image named "series, axis: value" ("Atlas 2, Reasoning: 88"), and a visually hidden table holds every number, with the series as columns and the axes as rows.
- The plot is one tab stop. Left and Right walk the axes, Up and Down the series, Home and End go to the first and last axis, and Escape lets go. Focusing a point reads it out beside the point and lights its series, as hovering it does.
- An axis with a `description` is a focusable label: its tooltip appears on hover or focus, and the sentence is also the label's accessible description.
- The legend is a row of toggle buttons (`aria-pressed`), each reachable with Tab. Color is never the only cue: every series is named in the legend, the readout and the table.
- Its built-in text comes from the labels, so `<YoujProvider labels>` translates it.

</ReferenceRow>
