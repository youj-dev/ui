## Installation & usage

<InstallTabs name="density-lanes" noImport />

Use density lanes for "when" across a few kinds of thing: alerts by hour per source, orders by half-hour per channel, commits by weekday per team. Each lane's shape tells when it's busy; the shares under the names tell how much of the whole it is. For one series of counts use a [Unit Chart](/docs/components/unit-chart); for a year of days, a [Calendar Heatmap](/docs/components/calendar-heatmap). The [Hour lanes](/docs/blocks/trends-and-comparisons#hour-lanes) card is built on it.

```tsx
import { DensityLanes } from '@youj/react'

<DensityLanes
  label="Alerts by hour"
  columns={hours}
  lanes={[
    { id: 'identity', label: 'Identity', values: identityByHour, tone: 'chart-3' },
    { id: 'network', label: 'Network', values: networkByHour, tone: 'chart-2' },
  ]}
  highlight={[[0, 6], [19, 23]]}
  marker={{ column: 12, label: 'Peak 12:00 · 504 alerts' }}
/>
```

`columns` names each column (in its tooltip and spoken), and every lane gives one value per column. A column swells `depth` dots (4 by default) above and below the lane's spine at `max` (by default the largest value, one scale for every lane), and a column with nothing draws no dots, only the faint grid. `ticks` places labels at column edges (`at` 0 is the start of the first column), by default one at each quarter. Lanes take the chart colors in order unless they set a `tone`; `shares={false}` drops the shares under their names; `formatValue` writes values with their unit. No lanes, or nothing in them, shows the empty state.

<ReferenceRow title="Accessibility" summary="Keyboard, focus, screen readers">

### Accessibility

- A named `grid` (your `label`, or the labels' "Density lanes") described by a summary: how many lanes, their total, and the busiest column with its value.
- A row per lane, its header the lane's name and share; every cell is named with its column and value, and says when it is in the highlight ("12:00: 504 alerts, highlighted").
- One tab stop. Left and Right walk the columns (mirrored in RTL), Up and Down the lanes, Home and End go to a lane's ends. Focus shows the cell's tooltip and marks its column through every lane, as hovering does.
- The dots, flag and axis are decorative; the cells say the same in words. Color is never the only cue: lanes are named, and a highlight is spoken.
- Its built-in text comes from the labels, so `<YoujProvider labels>` translates it.

</ReferenceRow>
