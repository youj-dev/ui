Give it `ChartTooltipContent`, which reads labels from the config and formats each value with `valueFormatter`. `indicator` sets the swatch (`dot`, `line` or `dashed`), and `hideLabel` drops the heading for single-series charts. `ChartLegend` lists series in the order they're drawn, not alphabetically, and `ChartLegendContent` renders them with their config labels.

<ChartTooltip content={<ChartTooltipContent indicator="line" valueFormatter={(v) => `$${Number(v).toLocaleString()}`} />} />
<ChartLegend content={<ChartLegendContent />} />

## Installation & usage

<InstallTabs name="chart" noImport />

Requires `recharts`, an [optional dependency](/docs/installation#optional-dependencies). Import it from `@youj/react/chart`.

The chart parts come from Recharts itself, so import them from `recharts` in your app.

Use a chart when the shape of the numbers is the point: a trend over time, a comparison between groups, a share of a whole. It's shadcn's chart, so you still write Recharts (`AreaChart`, `Bar`, `Pie`) and the kit supplies the container, the tooltip, the legend, the theme colors and the timing. For a trend the size of a word, in a KPI or a table cell, use a [Sparkline](/docs/components/sparkline). For one number and how it moved, use a [Stat Card](/docs/components/stat-card). When people need to sort, filter or copy the values, give them a [data table](/docs/blocks/tables-and-lists).

A `ChartConfig` names each series and gives it a color. `ChartContainer` exposes each one as `--color-<key>`, so the marks read `var(--color-revenue)`. Spread `useChartMotion()` onto each series for Youj timing.

```tsx
import { Area, AreaChart, XAxis } from 'recharts'
import { ChartContainer, ChartTooltip, ChartTooltipContent, useChartMotion, type ChartConfig } from '@youj/react/chart'

const config = {
  revenue: { label: 'Revenue', color: 'var(--color-chart-1)' },
} satisfies ChartConfig

export function Revenue({ data }: { data: { month: string; revenue: number }[] }) {
  const motion = useChartMotion()
  return (
    <ChartContainer config={config} className="h-56 w-full" title="Revenue by month" summary="Revenue doubled since April.">
      <AreaChart data={data}>
        <XAxis dataKey="month" tickLine={false} axisLine={false} />
        <ChartTooltip content={<ChartTooltipContent />} />
        <Area dataKey="revenue" stroke="var(--color-revenue)" fill="var(--color-revenue)" fillOpacity={0.2} {...motion.draw(0)} />
      </AreaChart>
    </ChartContainer>
  )
}
```

Point the config at the chart colors, `var(--color-chart-1)` to `var(--color-chart-5)`. They come from the theme: its own [chart palette](/docs/theming#chart-palette), which every preset tunes (Basalt's neon series, Graphite's calm blue, rose, violet, amber and teal), else one drawn from its accent. Either way light and dark and every [theme preset](/docs/theming) re-color the chart with no change to your code, and every series reads at 3:1 against the surface. Axes, grid lines and cursors take the ink ramp on their own.

### Size

`ChartContainer` is full width and `aspect-video` (16:9) by default, and it shrinks with its column, so a chart in a CSS grid or a flex row never pushes a phone page wider than the screen. A height class gives it a fixed height instead (`className="h-64"`), and an aspect class another shape (`aspect-square`).

### Series keys

Each config key becomes a CSS variable name. A key that isn't a CSS name, like `PM2.5` or `Net revenue`, has each character a name can't hold written as `-` (`--color-PM2-5`), and development warns once. `chartColor(key)` gives you a series' color for any key, so you never spell the variable yourself:

```tsx
import { chartColor, type ChartConfig } from '@youj/react/chart'

const config = {
  'PM2.5': { label: 'Fine particles', color: 'var(--color-chart-1)' },
} satisfies ChartConfig

<Bar dataKey="PM2.5" fill={chartColor('PM2.5')} />
```

### Donut center labels

A Recharts `Label` inside the `Pie` draws in the hole. Its `content` gets the hole's center as `viewBox`; write the total and its unit as two `tspan`s on the theme's text roles:

```tsx
<Pie data={traffic} dataKey="visitors" nameKey="source" innerRadius="62%" {...motion.sweep()}>
  <Label
    content={({ viewBox }) =>
      viewBox && 'cx' in viewBox ? (
        <text x={viewBox.cx} y={viewBox.cy} textAnchor="middle" dominantBaseline="middle">
          <tspan x={viewBox.cx} y={(viewBox.cy ?? 0) - 6} className="fill-fg text-2xl font-semibold tabular-nums">
            {total.toLocaleString()}
          </tspan>
          <tspan x={viewBox.cx} y={(viewBox.cy ?? 0) + 16} className="fill-fg-muted text-ui-xs">
            visitors
          </tspan>
        </text>
      ) : null
    }
  />
</Pie>
```

### Pie legends and tooltips

A pie's series are its rows, not its fields, so tell the legend and the tooltip which field names a slice: `nameKey`, the same one the `Pie` takes. Each slice's name is then looked up in the config for its label.

```tsx
<ChartTooltip content={<ChartTooltipContent nameKey="source" hideLabel />} />
<ChartLegend content={<ChartLegendContent nameKey="source" />} />
```

### A period filter that drives the charts

Keep the period in one piece of state: a `SegmentedControl` sets it from presets, a `DateRangePicker` sets a custom range, and every chart reads the rows inside it. A preset fills the picker; picking a range clears the preset.

```tsx
'use client'

import { useMemo, useState } from 'react'
import { SegmentedControl, SegmentedControlItem } from '@youj/react'
import { DateRangePicker, type DateRange } from '@youj/react/date'

const DAY = 86_400_000
const PRESETS = { '7d': 7, '30d': 30, '90d': 90 } as const

export function Overview({ rows, latest }: { rows: { date: Date; value: number }[]; latest: Date }) {
  const [preset, setPreset] = useState<keyof typeof PRESETS | ''>('30d')
  const [range, setRange] = useState<DateRange>({ from: new Date(latest.getTime() - 29 * DAY), to: latest })
  const shown = useMemo(() => rows.filter((r) => r.date >= range.from! && r.date <= range.to!), [rows, range])
  return (
    <>
      <div className="flex flex-wrap items-end gap-3">
        <SegmentedControl
          aria-label="Period"
          value={preset}
          onValueChange={(value) => {
            if (!(value in PRESETS)) return
            const key = value as keyof typeof PRESETS
            setPreset(key)
            setRange({ from: new Date(latest.getTime() - (PRESETS[key] - 1) * DAY), to: latest })
          }}
        >
          <SegmentedControlItem value="7d">7 days</SegmentedControlItem>
          <SegmentedControlItem value="30d">30 days</SegmentedControlItem>
          <SegmentedControlItem value="90d">90 days</SegmentedControlItem>
        </SegmentedControl>
        <DateRangePicker
          value={range}
          maxDate={latest}
          onValueChange={(next) => {
            if (!next?.from || !next.to) return
            setPreset('')
            setRange(next)
          }}
        />
      </div>
      <TrendChart rows={shown} />
      <BreakdownChart rows={shown} />
    </>
  )
}
```

Anchor the presets to the newest row (`latest`), not to the clock: the page renders the same on the server and in the browser, and a prerender never reads the time.

### Loading

While the rows load, show a `Skeleton` the chart's size in its place, so nothing moves when the chart arrives:

```tsx
import { Skeleton } from '@youj/react'

{loading ? <Skeleton className="aspect-video w-full" /> : <ChartContainer config={config}>…</ChartContainer>}
```

### Heatmaps: a value per cell

There's no general heatmap. For a value in each cell of a grid, pick the one that fits the grid:

- **A value by hour (or any column) for a few kinds:** [Density Lanes](/docs/components/density-lanes), one lane of dots per kind, swelling where it's busy.
- **A value by day, as a streak or a habit:** [Calendar Heatmap](/docs/components/calendar-heatmap), a day grid by week.
- **How well each row is covered by each column:** [Coverage Matrix](/docs/components/coverage-matrix), with the gaps hatched.

Recharts animates the marks itself. `useChartMotion()` replaces its 1.5s default ease with the token durations and curves, scaled by the Speed control, so a chart moves on the same clock as the rest of the page. The values it returns are plain numbers and strings, stable across renders, because Recharts restarts an animation whenever they change.

#### Reduced motion

Every mark is drawn in its final place, updates replace the old values at once, and the tooltip jumps to the pointer. The chart carries exactly the same information: only the transitions go.

### Accessibility

- `ChartContainer` is a figure (`role="figure"`) named by `title`. `summary` is read after the name, so say what the chart shows: the trend, the peak, the outlier.
- The plot is one Tab stop. The arrow keys walk the points and open the tooltip on each, and the ring shows on keyboard focus only.
- `ChartDataTable` gives the same numbers as a real table with a caption, column headers and row headers. Keep it hidden for screen readers, or put it behind View data, which is a disclosure button with `aria-expanded`.
- Color is never the only key: the legend and the tooltip name every series, and the table holds every value.

</ReferenceRow>
