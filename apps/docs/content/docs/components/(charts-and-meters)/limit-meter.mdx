## Installation & usage

<InstallTabs name="limit-meter" noImport />

Use an limit meter for a budget: what is left, large, with the spent and the limit as a quiet readout under it, over a ruler from zero to the limit. An index caret under the ruler points at the spend, and named lines mark the policies that act on it, so "how far until the card freezes" reads off the ruler.

```tsx
import { LimitMeter } from '@youj/react'

<LimitMeter
  spent={1240}
  limit={2000}
  format={{ style: 'currency', currency: 'EUR' }}
  markers={[{ value: 1800, label: 'freeze', tone: 'warning' }]}
  label="Card limit"
/>
```

The ruler has 50 minor intervals with a major tick every 10 (`ticks`, `majorEvery`), and zero, the middle and the limit labeled under it. The remainder's decimals are set quieter than its whole part, whatever the locale's currency format. For a unit Intl has none for (GB, kcal), pass `formatValue` instead of `format`: a function that writes every amount and the scale.

<ReferenceRow title="Accessibility" summary="Labels and assistive technology">

### Accessibility

- It's a `meter` (Base UI Meter) whose value is the spend and whose maximum is the limit. Name it with `label`; without one it's named by the visible "Remaining", which reads "Over limit" once the spend passes the limit.
- Its value text says it all: "€1,240.00 spent of €2,000.00, €760.00 left, freeze at €1,800.00". Every word comes from `labels` (`allowanceValueText`, `allowanceOverText`, `allowanceMarkerAt`, …), translated in all 14 language packs.
- The ruler is hidden from assistive tech. It runs from the inline start, so right to left in RTL.

</ReferenceRow>
