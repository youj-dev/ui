## Installation & usage

<InstallTabs name="forecast-band" noImport />

Use a forecast band for a total that only grows through a period (cloud spend, ad spend, API calls against a quota) when the question is where it lands and when it crosses the line. Spend so far is a solid ink line over a faint wash. From today the forecast carries on as a dashed line in its tone, inside its likely range, over a hatched projected area: solid for what's settled, hatched for what isn't, as in the [Hatched Bar](/docs/components/hatched-bar). The budget is a dashed line. If the forecast crosses it, the stretch above the line is hatched in danger and a marker lands on the crossing day, with its flag over the plot. For a budget read as what's left, use an [Limit Meter](/docs/components/limit-meter); for values over time with axes and tooltips, a [Chart](/docs/components/chart).

```tsx
import { ForecastBand } from '@youj/react'

<ForecastBand
  // The running total at the end of each elapsed day; the last one is today.
  actual={[412, 880, 1335 /* … */]}
  // The forecast running total for each remaining day, with its likely range.
  forecast={[{ value: 8500, low: 8370, high: 8710 } /* … */]}
  budget={12000}
  start="2026-09-01"
  format={{ style: 'currency', currency: 'USD' }}
/>
```

The period runs from `start` for as many days as `actual` and `forecast` hold between them. Its days are named in the locale ("Sep 28"). Without `start`, the crossing is named from today ("in 9 days") and the axis numbers the days. The scale tops out at a round number above the budget and the forecast's high. Pass `max` to hold it still when the data changes, so the axis stays put while the paths morph. For a unit Intl has none for (tickets, kWh), pass `formatValue` instead of `format`: a function that writes every amount and the axis labels.

The root has `data-state` (`over` or `within`). `tone` sets the forecast's color, a chart color by default, as `--forecast-tone`, and the scenario's tone is `--forecast-scenario-tone`. `--forecast-band-height` sets the plot's height (13rem). <ReferenceRow title="Accessibility" summary="Labels and assistive technology">

### Accessibility

- The plot is an `img` named by `label` (by default the labels' "Spend forecast"). It's described by a text summary: what's spent of the budget, the forecast at the period's end and its likely range, and the crossing day ("Crosses budget Sep 28") or "Stays within budget".
- The legend over the plot is a list of text, so it reads as it looks. The lines, the hatch, the marker and the axes are inside the image.
- Time runs from the inline start, like the kit's other rulers, so the plot mirrors in RTL. It holds no text; the flags and axis labels stay upright and in their own order.
- Its built-in text comes from the labels, so `<YoujProvider labels>` translates it.

</ReferenceRow>
