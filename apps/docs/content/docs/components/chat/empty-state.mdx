A greeting and four starter prompts above a composer, where picking one fills the composer.

It's one arrival, in order, then stillness. The icon tile's plates fan out, the greeting rises word by word from behind its line, the description fades in once the greeting has landed, and the suggestions stagger in two steps after that. The greeting's word count sets the timing, so a longer greeting pushes the rest back.

## Installation & usage

<InstallTabs name="chat" imports="ChatEmptyState" noImport />

Show it in place of the [message list](/docs/components/chat/message-list) until the first message is sent. It sets expectations (what this assistant can see and do) and offers [suggestions](/docs/components/chat/suggestions) so nobody faces a blank field. For empty views elsewhere in an app, use [Empty State](/docs/components/empty-state), the primitive this is built on.

```tsx
import { ChatEmptyState, ChatMessageList } from '@youj/react'

{messages.length === 0 ? (
  <ChatEmptyState
    greeting="Good morning, Ada"
    description="Ask about your deployments, logs and metrics."
    suggestions={starters}
    onSelect={(prompt) => {
      setDraft(prompt)
      composer.current?.focus()
    }}
  />
) : (
  <ChatMessageList>{/* … */}</ChatMessageList>
)}
```

Suggestions show when both `suggestions` and `onSelect` are set, as cards by default (`suggestionsLayout="chips"` for a row). `icon` replaces the tile's sparkles, and `children` render below everything else.
