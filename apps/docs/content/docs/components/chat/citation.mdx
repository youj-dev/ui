## Installation & usage

<InstallTabs name="chat" imports="ChatCitation, ChatSources" noImport />

Use citations whenever an answer draws on documents, search results or a knowledge base, so people can check a claim without leaving the conversation. Most of the time you don't render them yourself: pass `sources` to a [Chat Message](/docs/components/chat/message) and `[1]` in the text becomes `ChatCitation` for `sources[0]`, with `ChatSources` under the finished answer. Hover or focus a number in the preview to see its source.

```tsx
import { ChatMessage, type ChatSource } from '@youj/react'

const sources: ChatSource[] = [
  { title: 'Regions and pricing', url: 'https://youj.io/docs/regions', snippet: 'Per-region pricing for functions…' },
]

<ChatMessage role="assistant" content="fra1 is the cheapest at 10M requests a month [1]." sources={sources} />
```

A `ChatSource` has a `title` and a `url`, with an optional `snippet` for the preview and an `icon` (a favicon, say) to replace the domain's monogram. [Chat Markdown](/docs/components/chat/markdown) takes the same `sources` prop.

<ReferenceRow title="Accessibility" summary="Keyboard, focus">

### Accessibility

- Each marker is a link that opens its source in a new tab, named by its number and the source's title ("1, Regions and pricing"). The preview is a sighted convenience: the link carries everything.
- `ChatSources` is a list named by its `label`. A chip that already shows its title isn't named twice.
- Keyboard focus opens the preview like hover does, and Escape closes it.

</ReferenceRow>
