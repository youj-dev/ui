## Installation & usage

<InstallTabs name="chat" imports="ChatSuggestions" noImport />

Use suggestions for ways into a new conversation, or follow-ups under an answer. Picking one hands its prompt to `onSelect`, typically to fill the [Prompt Input](/docs/components/chat/prompt-input) and focus it, so people can edit it before sending. For a whole first-run screen with a greeting, use the [Chat Empty State](/docs/components/chat/empty-state), which includes them.

```tsx
import { ChatSuggestions } from '@youj/react'

<ChatSuggestions
  suggestions={[{ label: 'Show the diff' }, { label: 'Is a rollback safe?', prompt: 'Is rolling back to dpl_7c1e0b2 safe?' }]}
  onSelect={(prompt) => {
    setDraft(prompt)
    composer.current?.focus()
  }}
/>
```

Each suggestion has a `label`, and a `prompt` when what goes in the composer should differ from what the chip says. `delay` waits that many stagger steps before the first one arrives, to follow something else in.

</Example>

<ReferenceRow title="Accessibility" summary="focus">

### Accessibility

- The suggestions are a `group` named by `label` (default "Suggested prompts"), and each one is a real button.
- Picking one doesn't send it. Move focus to the composer in `onSelect`, as the examples do, so the next keystroke edits the prompt.
