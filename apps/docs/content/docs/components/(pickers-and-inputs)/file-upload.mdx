<Story id="demo" label="Demo">

<ComponentPreview name="file-upload/demo" height={380} />

A card of attachments that takes PNG, JPEG and PDF files up to 5 MB, six at most, uploaded by a simulated endpoint that fails every third file.

`onUpload(file, { signal, onProgress })` uploads one file. Report progress from 0 to 100 through `onProgress`, resolve when the upload is done, and reject or throw to show the error on the row with a Retry button. Removing a file while it uploads aborts `signal`, so pass it on to `fetch` or your storage client. Try the preview: every third file fails.

Files are checked against `accept` (extensions, MIME types or wildcards like `image/*`), `maxSize` in bytes, `maxFiles` and duplicates. Every rejected file is listed with its reason in one alert that grows in under the zone, so dropping ten files at once gives one explanation and not ten. `multiple={false}` keeps the picker to one file.

## Installation & usage

<InstallTabs name="file-upload" noImport />

Use it wherever people attach files: receipts on an expense, screenshots on a bug report, a spreadsheet to import, photos for a listing. The zone states the rules before anyone picks a file, a rejection says which file broke which rule, and each accepted file shows its own progress, a check when it's done, or the error with a Retry. For a single profile photo with cropping, use [Avatar Upload](/docs/components/avatar-upload).

```tsx
import { FileUpload } from '@youj/react'

export function Attachments() {
  return (
    <FileUpload
      accept=".png,.jpg,.jpeg,.pdf"
      maxSize={5 * 1024 * 1024}
      maxFiles={6}
      onUpload={(file, { signal, onProgress }) => uploadToStorage(file, { signal, onProgress })}
    />
  )
}
```

The zone is a button and a drop target: click it, press Enter or Space, or drag files onto it. Its second line is generated from the rules, such as "PNG, JPG or PDF · up to 5 MB each", and `hint` replaces it. `title` sets the main line.

</Example>

<ReferenceRow title="Accessibility" summary="Keyboard, focus, announcements">

### Accessibility

- The drop zone is a real button, so Enter and Space open the file picker, and its description reads the rules.
- Every change is announced politely: files added, rejections, each upload finishing or failing, and removals.
- Rejections are listed through a Field error under the zone, one line per file with its reason.
- Each row's buttons are named with the file name: "Cancel upload of receipt.pdf" while it uploads, then "Remove receipt.pdf", and "Retry receipt.pdf" after a failure.
- Focus never drops to the page: removing a row moves focus to the next row's button, or back to the zone when the list empties.

</ReferenceRow>
