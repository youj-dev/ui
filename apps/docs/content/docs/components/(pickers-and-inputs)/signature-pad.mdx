An agreement's signature field: sign, then Accept files it, and the signature locks, its line turning green with a small tick.

The pad is one surface: Draw | Sign by typing tabs across the top, the signing area, and a footer with Undo and Clear and the Accept button. Each stroke is one filled path that swells and thins: a pen's own pressure, or for a mouse or a finger a pressure taken from speed (fast is thin). Accept is the kit's AsyncButton: it awaits `onAccept(value)` (spinner), draws its check, and the signature locks: read-only, its line in the success ink with a small tick at the end, its ink settled onto the line. A rejection shows its message on the button and leaves the pad open; Re-sign unlocks a locked signature.

## Installation & usage

<InstallTabs name="signature-pad" noImport />

Use a Signature Pad where a person consents or confirms by signing: agreements, deliveries, check-ins. Take the signature in `onAccept`: the button waits for it, and the pad locks once it resolves.

```tsx
import { useRef, useState } from 'react'
import { Field, FieldLabel, SignaturePad, type SignaturePadHandle, type SignatureValue } from '@youj/react'

export function Agreement() {
  const pad = useRef<SignaturePadHandle>(null)
  const [signature, setSignature] = useState<SignatureValue | null>(null)
  return (
    <Field>
      <FieldLabel>Signature</FieldLabel>
      <SignaturePad
        ref={pad}
        value={signature}
        onValueChange={setSignature}
        onAccept={() => upload(pad.current!.toSVG())}
      />
    </Field>
  )
}
```

The value is `{ kind: 'drawn', strokes }` or `{ kind: 'typed', text }`, and `null` while the pad is empty. A stroke is a list of `[x, y, pressure]` points, x and y as fractions of the pad's width, so the pad can resize (it keeps `aspectRatio`, 3 by default) and the signature scales with it. The ref's `toSVG()` returns a standalone SVG document and `toDataURL(scale)` a PNG on a transparent ground, both in the ink color of the moment; `clear()` and `undo()` work the pad. `locked`, `defaultLocked` and `onLockedChange` hold the lock from outside, say to show a signature on file already accepted.

<ReferenceRow title="Accessibility" summary="Keyboard, ARIA, typing instead">

### Accessibility

- Draw and Sign by typing are tabs: arrow keys move between them, Enter or Space chooses one. Choosing Sign by typing puts the caret in its field.
- The drawing area is a focusable group named by its Field label (or `label`) and described by a hint: draw with a pointer, or press Enter to type the name instead. ⌘Z or Ctrl+Z on it undoes a stroke.
- Sign by typing is a text field, so a signature never needs a pointer: type, then Tab to Accept.
- Undo and Clear are named buttons with tooltips; a clear is announced in a polite live region.
- Accept announces its progress and outcome (an error assertively); once it settles, the lock is announced politely, and the locked pad reads "Signed" with the time. Re-sign's unlock is announced too.
- With `required`, a pad without an accepted signature stops a native submit and moves focus to the pad (or to Accept when there is a draft); the Field's error explains why.

</ReferenceRow>
