## Installation & usage

<InstallTabs name="slide-to-confirm" noImport />

Use a Slide to Confirm for an action that is costly to trigger by mistake, such as a payment, a transfer or a deletion, where a dialog would interrupt more than it helps. For a lighter guard on a button, use `hold` on an [Async Button](/docs/components/button#hold).

```tsx
'use client'

import { SlideToConfirm } from '@youj/react'

export function PayInvoice({ invoice }: { invoice: Invoice }) {
  return (
    <SlideToConfirm
      label={`Slide to pay ${invoice.total}`}
      confirmingLabel="Paying…"
      confirmedLabel="Paid"
      onConfirm={() => pay(invoice.id)}
    />
  )
}
```

`onConfirm` is awaited: resolve for success, reject or throw for an error. It runs once per confirmation, and a second confirm while it runs is ignored. Once confirmed the control stays confirmed; give it a new `key` to offer it again. It sizes to its container up to `max-w-sm`; pass a `className` to change that.

</Example>

#### Data attributes

The root carries `data-state` (`idle`, `confirming`, `confirmed` or `error`), `data-size` (`sm`, `default` or `lg`) and `data-tone` (`default` or `danger`), plus `data-dragging` while the thumb is held and `data-disabled` when disabled. The thumb's position is `--ui--slide`, from 0 to 1.

<ReferenceRow title="Accessibility" summary="Slider role, keyboard, announcements">

### Accessibility

- The thumb is a `slider` (0 to 100) named by `label` and described by a hint: use the arrow keys or End to reach the end, then press Enter.
- Arrow keys step by 10, Home and End jump to either end, and Enter at the end (90% or more) confirms. In right-to-left, the arrow keys follow the mirrored track. A thumb left short of the end goes back when it loses focus.
- While confirming and once confirmed, the slider is read-only and its value text is the state's label. Confirming and confirmed are announced politely, an error assertively.
- `disabled` takes the thumb out of the tab order and sets `aria-disabled`.

</ReferenceRow>
