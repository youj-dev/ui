## Installation & usage

<InstallTabs name="action-island" noImport />

Use an action island for the few actions that belong to a canvas, a preview or a map, and that should float above it. Each action is its own tile, a pressed tile marks the view that's showing, and one primary tile is the next step. For a dense row of editing controls, use a [Toolbar](/docs/components/toolbar).

```tsx
import { ActionIsland, ActionIslandGroup, ActionIslandMark, ActionIslandSeparator, ActionIslandTile } from '@youj/react'
import { CodeIcon, EyeIcon, LayersIcon, SparklesIcon } from '@youj/icons'

export function Viewer() {
  return (
    <ActionIsland aria-label="Preview actions">
      <ActionIslandMark aria-hidden>
        <LayersIcon />
      </ActionIslandMark>
      <ActionIslandGroup aria-label="View">
        <ActionIslandTile label="Preview" pressed>
          <EyeIcon />
        </ActionIslandTile>
        <ActionIslandTile label="Code" pressed={false}>
          <CodeIcon />
        </ActionIslandTile>
      </ActionIslandGroup>
      <ActionIslandSeparator />
      <ActionIslandTile label="Open" variant="primary" showLabel>
        <SparklesIcon />
      </ActionIslandTile>
    </ActionIsland>
  )
}
```

Every tile is an icon with a `label`: its tooltip, and its accessible name. `showLabel` draws the label beside the icon, for a primary action. `ActionIslandMark` names what the island acts on and isn't a control. Pass `render` to make a tile a menu's trigger or a link.

</Example>

<ReferenceRow title="Accessibility" summary="Keyboard, ARIA">

### Accessibility

- The root is a `toolbar`; name it with `aria-label`. It's a single tab stop, and the arrow keys move between tiles and wrap at the ends, mirrored in right-to-left layouts. Home and End jump to the ends.
- A pressed tile exposes `aria-pressed`. A disabled tile stays in the arrow-key order.
- A tile's `label` is its accessible name and its tooltip, which also opens on a long press on touch. The mark is out of the tab order; hide it with `aria-hidden` when it's only an icon.

</ReferenceRow>
