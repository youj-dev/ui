Four icon toggles whose icons morph between their two states as you press.

A Youj state icon inside a toggle can follow the pressed state through its `active` prop. It morphs to its second state as the toggle presses, and a quick second press reverses it from wherever it is.

```tsx
<Toggle aria-label="Pin project" pressed={pinned} onPressedChange={setPinned}>
  <PinIcon active={pinned} />
</Toggle>
```

## Installation & usage

<InstallTabs name="toggle" noImport />

Use a toggle for a view or formatting option that applies at once and is read from the button itself: pressed means on. For a setting in a form or a settings list, use a [Switch](/docs/components/switch). For a set of related options, use a [Toggle Group](/docs/components/toggle-group), and for a one-off action, a [Button](/docs/components/button).

```tsx
import { useState } from 'react'
import { Toggle } from '@youj/react'
import { CornerDownLeftIcon } from '@youj/icons'

export function WrapLines() {
  const [wrap, setWrap] = useState(false)
  return (
    <Toggle variant="outline" pressed={wrap} onPressedChange={setWrap}>
      <CornerDownLeftIcon />
      Wrap
    </Toggle>
  )
}
```

Use `pressed` and `onPressedChange` to control it, or `defaultPressed` to let it hold its own state. Pressed reads as a filled neutral key with full-strength text. The accent stays reserved for actions.

## Reference

<ReferenceRow title="Props" summary="sound, variant, size (3)">

### Props

<PropsTable name="Toggle" />

The state comes from Base UI's Toggle, and these are the props you'll reach for:

| Prop | Type | Description |
| --- | --- | --- |
| `pressed` | `boolean` | Controlled state. |
| `defaultPressed` | `boolean` | Initial state when uncontrolled. Default `false`. |
| `onPressedChange` | `(pressed: boolean, details) => void` | Called when the user toggles it. |
| `disabled` | `boolean` | Ignores presses. |
| `value` | `string` | Identifies it inside a Toggle Group. |

</ReferenceRow>

#### Reduced motion

The press doesn't scale. Colors still change, so the pressed state reads the same, and a state icon switches to its second state instantly instead of morphing.

<ReferenceRow title="Accessibility" summary="Keyboard, ARIA, announcements">

### Accessibility

- It's a `<button>` with `aria-pressed`. `Space` and `Enter` toggle it.
- Keep the name constant and let `aria-pressed` carry the state: a toggle named "Pin project" is announced as pressed or not pressed. Don't swap the label between "Pin" and "Unpin".
- Icon-only toggles need an `aria-label`. A Youj icon inside is decorative unless you label it.
- For a group of related toggles, use a [Toggle Group](/docs/components/toggle-group), which gives them one tab stop and arrow-key navigation.

</ReferenceRow>
