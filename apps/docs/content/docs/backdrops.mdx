Some blocks in these docs stand on a backdrop: a soft, grainy ground where the card is the only sharp thing, the way a launch page would show it. Each backdrop has a light and a dark version, each designed for its mode, and a preset of the same name. The preset's accent, neutrals and chart colors come from the same combination as the backdrop, so the block and its ground read as one scheme. Switch the site to dark to see the other side.

Palettes drawn from Sanzo Wada's *A Dictionary of Color Combinations* (1933–34).

In a block's preview, the Appearance menu still switches the block to any other preset; the backdrop stays.

## Use one

The ones drawn in code ship as [Atmosphere](/docs/components/atmosphere), in `@youj/motion/backgrounds`. Put it in a positioned section behind your card, and wear the preset of the same name:

```tsx
import { meadow, YoujProvider } from '@youj/core'
import { Atmosphere } from '@youj/motion/backgrounds'

export function Launch() {
  return (
    <YoujProvider theme={meadow}>
      <section className="relative isolate grid min-h-dvh place-items-center p-6">
        <Atmosphere scene="meadow" />
        <YourCard />
      </section>
    </YoujProvider>
  )
}
```

It follows light and dark on its own, holds one still frame under reduced motion, and is a CSS gradient with grain where WebGL2 isn't available.

Seaglass and Heather are photographs, so they stay on this site; their presets ship like the others. To do the same with a photograph of your own, soften it and grade it toward the preset's colors, keep it small (these are 2400 × 1500 WebP files of about 20 KB), and lay it behind the card as a background image.

## The presets

Meadow, Sandstone, Cinnabar, Umber, Seaglass and Heather are full presets, exported by their ids from `@youj/core` and listed in [Theming](/docs/theming#presets) with the others. Each is its palette in the Clean style (Inter, rounded corners, precise motion), and each passes `checkTheme` in light and dark: text at 4.5:1 on every surface, chart series at 3:1, with neighboring series apart for readers with red-green color blindness. Wada's swatches were moved in OKLCH only as far as those checks needed, keeping their hues.
