Use it for disclosure you build yourself: a filter panel, "show more", an inline error, a settings section. The content below moves with the height instead of jumping. For Base UI's Collapsible and Accordion, use the [`yj-collapse`](/docs/motion/presets) preset on the panel instead, or @youj/react's [Collapsible](/docs/components/collapsible) and [Accordion](/docs/components/accordion), which already do.

## Usage

The trigger owns the state. Give the panel an `id`, and point the trigger's `aria-controls` and `aria-expanded` at it.

```tsx
import { useId, useState } from 'react'
import { Collapse } from '@youj/motion'

export function Filters() {
  const id = useId()
  const [open, setOpen] = useState(false)

  return (
    <>
      <button type="button" aria-expanded={open} aria-controls={id} onClick={() => setOpen(!open)}>
        Filters
      </button>
      <Collapse id={id} open={open}>
        <FilterForm />
      </Collapse>
    </>
  )
}
```

Other attributes pass through to the panel, so it can carry a `role`, an `aria-labelledby` or a class.

<Example id="interrupting" label="Interrupting">

### Interrupting

The height eases to and from the content's own height, so there's nothing to measure or hard-code. Press Filters twice in quick succession: a reversal starts from the current height and heads back on the same curve, with no jump. Content added while the panel is open grows it normally, because at rest the height is `auto`.

The panel clips only while it moves or while it's closed. At rest nothing is clipped, so focus rings and popovers inside it aren't cut off.

</Example>

### Keeping state

By default the content unmounts once it has collapsed. With `keepMounted`, it stays in the DOM while closed, hidden and inert, so a half-filled form or a scroll position survives. `duration` sets the height's duration token, `base` by default. This section uses `slow` for a taller panel.

Height is a layout animation, and here that's the point: the content below has to move. Keep panels to the size of a section. For whole pages, use a route transition.

#### Reduced motion

The panel shows and hides at once, with no height animation and no fade. What's shown and what's reachable are exactly the same as with motion.

<ReferenceRow title="Accessibility" summary="ARIA, focus">

### Accessibility

- Collapse adds no roles or state of its own. The trigger carries `aria-expanded` and `aria-controls`, as in the examples. Add `role="region"` and `aria-labelledby` when a panel is a landmark worth jumping to.
- Closed content is `inert` from the first frame of the close, so it can't take focus or clicks while it collapses. It then unmounts or, with `keepMounted`, is hidden from assistive technology.
- Keep the trigger in place while the panel moves. It sits outside the panel, so it never shifts under the pointer.

</ReferenceRow>
