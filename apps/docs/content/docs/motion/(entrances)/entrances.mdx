<TopicLoop topic="entrances" />

An entrance plays over UI that's already rendered. It reads the parts on the page, orders them from the outside in, and builds them up in its own style. When it ends, the page is exactly the real UI: nothing moves, nothing is left behind, and it skips itself under reduced motion. Every entrance shares the same options for `duration`, `speed` and `phases`, and can be cancelled at any moment.

## On this site only

Code (experimental) types out a demo's source beside it, and each line becomes its part as it's typed. It needs the demo's source as text, which a running app doesn't have, so it isn't in the library yet. Try it from the Entrance menu on any preview in these docs, where every demo's source is published.
